# AI 主导开放世界 · 改造方案（调研稿）

> 2026-09-17 · 依据：本仓库功能盘点 + 网游小说/修仙游戏机制调研  
> 约束：文字 LAN · 单进程 · 规则权威 + LLM 叙事 · 有 AI 预算上限  
> **本稿只做方案，未写业务代码**

---

## 0. 一句话判断

当前是「**规则骨架完整、AI 做旁白**」的可玩局域网修仙；离「**世界自己活、AI 主导叙事与势力**」还差三块主战场：

1. **跨主体**——NPC 仍是孤岛（议程明文禁止合谋）  
2. **跨时间**——事件单发、大劫后世界几乎不记得你  
3. **通道与记忆**——AI 断则全塌；秘境/预算/议程重启即失忆

## 2. 灵魂拷贝：可抄的核心循环（游戏/小说）

| 来源 | 游戏化一句话 | 本作是否已有 |

## 3. 差距：有骨架但 AI 主导感不足

| 系统 | 现状缺口 |
|---|---|
| NPC 议程 | 单议程、每 tick 最多 5 人、冷却长；**禁止跨 NPC 联盟** |
| 世界事件 | 单发；无 2–3 步事件链、无势力版图回写 |
| `/做` 自由言行 | 白名单意图+叙事，不驱动 NPC/势力状态机 |
| 心魔 | 会话问心，无长期心魔史 |
| 大劫/赛季 | 有结算，无「传说库」跨纪元回流 |
| 宗门 | 白给俸禄；无贡献、敌对、任务派发、宗门战 |

**完全缺失**：NPC 关系网合谋 · 师徒/结拜指令 · 纪元传说 · 宗门战 · 可感知天道 UI · 真联机。

**技术债**：AI 通道单点 · 秘境/预算等内存态重启丢 · 网页缺行囊/穿戴面板。

## 4. 改造方案（三档）

### 档 A · 立刻增强「AI 主导感」（推荐第一批）

| ID | 主题 | 最小闭环 | AI/规则 |
|---|---|---|---|
| **A1** | **坊间传闻池** | 重大事件入池；NPC 交谈注入扭曲/隐瞒；玩家可 `/传闻` | 规则维护池，LLM 口播 |
| **A2** | **NPC 社会关系网** | 关系边（仇/恩/师徒/宗门）+ 同场合议事件；去掉「禁止合谋」硬闸 | 规则图谱，LLM 写合谋台词 |
| **A3** | **自主议程升级** | 欲望标签（求道/复仇/夺宝）驱动「今日意图」；无玩家 tick 也能推进 | 规则调度，LLM 行为描述 |
| **A4** | **奇遇触发树** | 按境界/地点/因果分支；奖励表钳死 | AI 叙事，规则发奖 |

### 档 B · 世界活性与长线

| ID | 主题 | 最小闭环 | AI/规则 |
|---|---|---|---|
| **B1** | **世界叙事引擎（事件链+纪元传说）** | 2–3 步链；结局写大事记；大劫后传说可检索 | 规则链状态机，LLM 分叉叙事 |
| **B2** | **宗门贡献+跑环/敌对** | 上交/环任务→贡献→兑换；宗门间敌对影响安全区/任务 | 纯规则+少量 AI 委托文案 |
| **B3** | **师徒/结拜** | 指令+因果链「师徒/恩」；传功冷却与声望 | 规则契约，LLM 仪式叙事 |
| **B4** | **坊市区域价差（跑商）** | 地点库存→买低卖高 | 纯规则 |
| **B5** | **世界 Boss / 全服公告** | 定时/条件触发大妖；多人可集结 | 规则胜负，AI 播报 |
| **B6** | **心魔状态机** | 走火/道心裂痕影响下次突破与闭关 | 规则状态，LLM 心魔对白 |

### 档 C · 地基（不性感但必须）

| ID | 主题 | 最小闭环 |
|---|---|---|
| **C1** | AI 通道硬化 | 健康探测、失败明确提示、可选多 Key |
| **C2** | 世界态持久化 | 秘境开启、AI 预算、议程进度入 SQLite |
| **C3** | 可感知天道 UI | 大限/血煞/天机显影进 `/look` 与网页 |
| **C4** | 行囊/穿戴/功法网页面板 | 与指令对齐 |

### 暂缓（人少/成本高）

真·多端联机架构 · 仙晶付费 · 著书立说高成本 AI · 跨服比武 · 复杂物流护镖。

---

## 5. 推荐节奏（两周示意）

```
第 0 刀（半天~1 天）  C2 世界态持久化 + C1 通道提示     ✅ 已交付
第 1 批（4~5 天）    A2 关系网 + A3 自主议程 + A1 传闻池  ✅ 已交付（合谋最小闭环）
第 2 批（4~5 天）    B1 事件链+纪元传说 + B3 师徒
                    → 验收：链跑通且传说跨大劫存活
第 3 批（可选）      B2 宗门贡献/环 + B5 世界 Boss + C3/C4
```

**主题排序逻辑**：先让「没有你世界也在转」（A），再让「世界记住你」（B1），最后补经营与展示（B2/C）。

---

## 6. 验收原则（沿用项目门禁）

1. 每主题一份 `docs/compose/spec/<name>.md`  
2. AI 只提案，数值/胜负/掉落规则钉死  
3. 全量 pytest 不回归 + 新功能至少一条可观察验收  
4. 无 AI 时：核心循环可降级本地/拒绝并提示，不静默假装
