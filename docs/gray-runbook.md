# 灰度运行手册（v0.3.4-gray.11）

给灰度房主的一页纸：开服、自检、邀请、备份、排障、回滚。

## 1. 开服清单
1. Python 3.10+（推荐 3.12），`python -m venv .venv` 后激活，
   `pip install -r requirements.txt`。
2. 复制配置：`cp .env.example .env`，至少填好 `LLM_API_KEY`
   （或改 `USE_CCSWITCH=1` 走本机 Claude Code 代理）。
   正式灰度保持 `ALLOW_LOCAL_AI=0`；无 Key 联调才临时开 1。
   主通道超时 `LLM_TIMEOUT_SECONDS` 默认 30 秒；走慢中转或慢模型时建议调大
   （如 60，可调区间 5–120），改后重启生效。
3. 起服（二选一）：
   - 局域网网页服：`python -m server.run`（默认 0.0.0.0:8765）
   - 单机命令行：`python -m cli.main`
4. 自检：浏览器或 curl 打开 `http://<房主IP>:8765/health`，应看到
   `"version": "0.3.4-gray.11"`、`"ai_available": true`、`"online": <在线会话数>`。
   - 注意：`ai_available` 只表示「已配置通道」（填了 Key 或接了 CCSwitch），
     **不代表 Key 有效、接口连通**；填错 Key 时它照样是 true。
     真正确认连通：进游戏发一句 `/交谈` 或看 `/ailog` 最近调用有无报错。
   - `ai_available=false` 且 `ai_required=true`：AI 没配，玩家交谈/斗法会被拒，先别邀人。
   - `allow_local_ai=true` 时即使 `ai_available=false`，交互也会走本地模板降级（仅联调用）。

## 2. 邀请玩家
- 玩家与房主连同一局域网；玩家打开 `web/index.html`，在页面里填房主地址
  `http://<房主IP>:8765` 与道号即可入世（或先在页内注册账号再登录）。
- 手机版：手机打开根地址 `http://<房主IP>:8765/` 自动进入移动版（单列 + 底部导航）；
  桌面版点「手机版」/ 移动版点「桌面版」可双向切换并记住选择；
  `?view=mobile|desktop` 仅本次生效（逃生口）。
- 建议灰度规模：3–10 人、同一赛季内进场；新手有 72 小时保护期。
- 先说清核心规则：1 游戏年 = 现实 1 天，寿尽即坐化，一世结束看道统结算。

## 3. 存档与备份
- 全部存档在 `data/tiandao.db`（SQLite）。**停服后**再拷贝整个 `data/` 目录备份，
  建议每现实日一份，文件名带日期。
- 恢复：停服 → 用备份覆盖 `data/` → 起服，进游戏 `/道身` 核对角色。
- 重置世界（慎重，不可逆）：停服 → 删除或改名 `data/tiandao.db` → 起服自动建新界。

## 4. 排障速查
| 现象 | 先看 | 处理 |
|---|---|---|
| 玩家说「AI 不可用 / 天机未通」 | `/ailog` 最近调用报错、游戏内发一句 `/交谈` 实测 | Key 失效、余额不足或接口不通（`/health` 的 `ai_available` 只看配没配，不验连通） |
| 玩家进不来 | 房主防火墙、IP 是否同网段 | 放行 8765 端口；确认填的是房主局域网 IP |
| 数值没变/事件没触发 | 先分清规则与叙事 | 数值永远由规则引擎裁决，AI 只写叙事；把玩家道号+时间+指令记进反馈 |
| 服卡死/异常 | 终端输出与 `data/` 是否只读 | 重启服即可，会话需玩家重新登录，角色数据不丢 |

## 5. 反馈收集（统一格式）
道号 / 发生时间（现实）/ 所在地点 / 输入的指令或点的按钮 / 期望 vs 实际 / 截图可选。
灰度阶段优先收三类：进不去、看不懂、数值不对 — 分别对应环境、体验、规则。

## 6. 回滚
本版 tag：`v0.3.4-gray.11`。需要退回上一稳定点：
`git checkout v0.3.3-gray.10`（对应基线提交 `0b43abf`）后按第 1 节重起服；
再上一稳定点为 `v0.3.2-gray.9`；
存档若已在新版跑过，优先用第 3 节的停服备份恢复，不要混用新旧库。

## 7. 已知限制（本版不解决）
- 局域网单进程形态，不支持公网直连与多服；关机/停服即世界暂停（寿元按墙钟走，见游戏内说明）。
- AI 单通道：通道故障时交互叙事受影响，规则玩法（闭关/坊市/突破）仍可进行的部分以游戏内提示为准。
- 灵宠、心法槽位等加厚玩法未做，留待灰度反馈后排期。
