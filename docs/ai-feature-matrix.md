| `/归隐` `/出隐` `/下线` | 庇护与逃遁 | 规则 | 无 | 正常 |
| `/坊市` `/购买` `/出售` `/服用` `/寄存` | 商会交易 | 规则 | 无 | 正常 |
| `/目标` | 六类目标源 | 规则 | 无（机缘目标可由事件/AI 后续叠加） | 正常 |

| `/转世` `/legacy` | 道统 | 规则 | 无 | 正常 |

## 三、AI 网关能力（`ai/gateway.py`）

| 接口 | 用途 | 失败降级 |
|---|---|---|
| `judge_tribulation` | 天劫成败 | 规则骰 |
| `judge_combat` | 斗法结局 | 本地 standoff / 规则伏击 |
| `judge_free_action` | 自由言行意图+叙事 | 本地关键词意图；正式模式无 AI 则拒 |
| `generate_world_event` | 机缘/危机/异象 | 本地事件池 |
| `generate_heart_demon_session` / `judge_heart_demon_choice` | 心魔 | 本地心魔结果 |
| `generate_heart_demon_text` | 心魔叙事 | 本地短传 |
| `generate_custom_art` | 自创功法 | DSL 校验失败丢弃 |
| NPC 对话 / 议程 tick / 主动搭话 | 世界活性 | 本地模板或跳过 |

通道：
- **OpenAI 兼容**：`LLM_API_BASE` + `LLM_API_KEY`（直连；`ps.air-outer.com` 对 Python 会 401）
- **CC Switch**：`USE_CCSWITCH=1` → 本机 `127.0.0.1:15721` Anthropic `/v1/messages`

## 四、建议优先级（若要「AI 感更强」）

1. **打通可用 AI 通道**（CC Switch 切健康账号，或换 OpenAI 兼容站）——否则交谈/事件/斗法/言行全是本地。  
2. **交谈**（已补上下文）与 **`/做` 自由言行** ——玩家最常感知。  
3. **世界事件 + NPC tick** ——世界「自己活」。  
4. **天劫天命判词** ——高光时刻叙事。  
5. **心魔** ——高成本高回报，可后置。

---

## 五、明确「不需要 AI」的功能（别误接）

迁跃、闭关结算、灵气稀释、庇护/逃遁、坊市买卖/寄存、目标、六榜、宗门数值、秘境链步进、悬赏、转世道统、赛季时钟、寿元。
