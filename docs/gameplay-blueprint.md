## 1. 总设计哲学（三句话）

1. **寿元是硬通货**——一切行动烧年；突破是唯一「改命」；大限让你不敢肝。  
2. **世界不需要你也在转**——NPC 有欲望、有仇怨、会合谋；你不在时消息照样进频道。  
3. **你死后世界记得你**——传说、仇家、未竟的委托、道统，进入下一世与下一纪。

## 2. 五大支柱系统（加厚）

### 支柱 I · 一世道途（个人成长弧）

现有：修炼 / 突破 / 大限 / 转世道统 / 功法 / 装备。

**加厚项：**

| 系统 | 玩法 | 最小闭环 | AI/规则 |
|---|---|---|---|
| **I1 心法槽位** | 心法/身法/术法三槽；同系共鸣加成，异系冲突扣效 | `/功法` 显示槽；战力与闭关倍率按槽算 | 纯规则 |
| **I2 心魔状态机** | 走火/道心裂痕/执念：影响突破概率与闭关效率；可闭关「炼心」清除 | 状态字段 + 突破前检定 | 规则状态，AI 写心魔对白 |
| **I3 血煞显影** | 业力≥阈值：`/look` 与网页显「血煞缠身」；安全区外人人可诛；天劫加难 | 已有 karma，补 UI 与天劫修正 | 规则 |
| **I4 大限观气** | 剩余寿元分档文案（鹤发/油尽灯枯）；临近时目标系统强推「延寿/突破」 | `/道身` 分档 | 规则文案 |
| **I5 肉身/神识双修（轻）** | 闭关可选「炼体」或「炼神」：体→战力，神→突破率；不可双开 | `/闭关 体\|神` | 纯规则 |
| **I6 灵宠（轻）** | 探险掉幼崽；喂养升阶；加战力或闭关效率；可战死 | 宠物字段 + 3 阶 | 规则，无独立 AI |

**一世理想节奏（k1 验收已有）：**  
入世 → 练气（1–2 天现实）→ 筑基渡劫（新手期）→ 金丹（寿元中期）→ 元婴/化神（少数）→ 大劫飞升或转世。

### 支柱 II · 天道自衡（冲突与因果）

现有：三护栏、业力、悬赏、复仇回访、斗法 AI 结局、大劫。

**加厚项：**

| 系统 | 玩法 | 最小闭环 | AI/规则 |
|---|---|---|---|
| **II1 除凶令** | 血煞者自动挂「天道标记」； `/接除凶` 类似悬赏但零赏金、得功德 | 状态 + 接令 | 规则 |
| **II2 围剿** | 同场 ≥2 名玩家/NPC 对同一血煞目标时，斗法 power 联合加成 | 同场检定 | 规则 |
| **II3 诺言账** | `/许诺 <名> <事>` 简短承诺；违背记业力；兑现记功德 | 因果链「诺」 | 规则 + AI 叙事 |
| **II4 夺舍/借尸（高风险）** | 陨落后小概率可「借」低境界 NPC 身（一纪一次）；失败则真灵散 | 转世分支 | 规则 |
| **II5 天机显影** | 高业力者 `/探查` 可见方位；隐身/归隐失效一段时间 | 已有 blood_mark 扩展 | 规则 |

### 支柱 III · 世界自己活（NPC 与势力）

现有：心智/议程/主动搭话/关系边/合谋/传闻。

**加厚项：**

| 系统 | 玩法 | 最小闭环 | AI/规则 |
|---|---|---|---|
| **III1 欲望标签升级** | 每 NPC 固定主欲望（求道/复仇/夺宝/称尊/苟活）；议程与合谋权重跟欲望走 | roster 字段 + tick 权重 | 规则 |
| **III2 势力版图** | 四大宗门实力条（人数×境界+贡献）；某宗独大 → 其驻地外冲突区扩大 | 数值条 + 安全区开关 | 规则 |
| **III3 宗门敌对/结盟** | 杀同门 → 敌对；传功/救援 → 结盟；敌对宗门弟子不可互相寄售 | 关系边「敌对/盟」 | 规则 |
| **III4 NPC 日程可视化** | `/世情` 列出「谁在闭关/谁在寻仇/谁在坊市」 | 议程表 | 规则 |
| **III5 委托链** | NPC 发 2 步委托（送信→护送）；完成升态度+贡献；失败记仇 | 链模板 | 规则效果，AI 文案 |
| **III6 长老议政（低频）** | 每现实日 1 次：宗门长老「决议」一条（增税/开秘境/通缉某人）写入频道 | 定时规则 | AI 檄文可选 |

## 3. 「一日循环」体验设计（玩家体感）

目标：**每天上线 15–40 分钟有明确钩子**，不是无限日常清单。

```
上线
 ├─ /频道：看世界刚发生了什么（击杀/落槌/大劫预兆/合谋闲话）
 ├─ /目标 + /世情：今日钩子（突破窗口 / 悬赏 / 秘境开启 / 宗门环）
 ├─ 主行动 1 次：
 │    闭关冲刺 | 探险 | 接委托 | 当面/拍卖 | 斗法除凶
 ├─ 社交 0–2 次：交谈/许诺/师徒传功
 └─ 下线：归隐或安全区；世界继续 tick
```

**刻意不做**：每日打卡 N 环强制；无限刷怪日常。  
**替代**：世界事件驱动的「今日值得做」——秘境开、大妖现、拍卖专场、长老议政。

## 4. AI 预算分配（宁少而准）

| 优先级 | 用途 | 频率建议 |
|---|---|---|
| P0 | 玩家 `/交谈` `/做` `/斗法` 结局 | 按玩家操作 |
| P1 | 大事件频道文案润色（击杀/大劫） | 有事件才调 |
| P2 | NPC 合谋/委托叙事 | 每 tick ≤1 |
| P3 | 奇遇链开场润色 | 触发时 |
| P4 | 著书立说 | 玩家付费/高门槛 |
| 禁止 | 每条传闻都调 AI；每分钟 NPC 全量对话 | — |

传闻、价差、贡献、掉落：**零 AI**。

## 7. 明确仍不做
