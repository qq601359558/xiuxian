# 规格说明：修仙境界突破天命裁决与纳戒真实落账修复 (breakthrough-and-inventory-fix)

## 1. 痛点问题 (Problem)
1. **境界推算荒谬**：前端此前破境大典写死“化神后期 ➔ 炼虚初期”，完全脱离角色真实境界（如练气初期），突破成功后直接把境界赋值为炼虚初期。
2. **缺乏门禁与天劫无常**：
   - 修为未满 100% 时仍可点击突破；
   - 每次突破均 100% 必定成功，架空了后端已有的 AI 大模型天命判定与规则裁决；
   - 未区分小阶顿悟与大境界天劫。
3. **仙鹤机缘纳戒隐形**：
   - `ensureDefaultInventory` 在纳戒物品少于 10 件或首次切换时会暴力重置覆盖已获得物品；
   - 仙鹤探路物品使用了非标准的 `kind: "map"`，纳戒筛选器只认 `treasure_map`，且缺少方位坐标与风水定盘元数据；
   - 联机模式未打通服务端真实背包同步。

## 2. 详细设计 (Design)

### 2.1 真实境界演进算法与门禁
- 境界阶梯序列：
  `练气期` (0) ➔ `筑基期` (1) ➔ `金丹期` (2) ➔ `元婴期` (3) ➔ `化神期` (4) ➔ `炼虚期` (5) ➔ `合体期` (6) ➔ `大乘期` (7) ➔ `渡劫期` (8) ➔ `真仙` (9)
  子阶：`初期` (0) ➔ `中期` (1) ➔ `后期` (2) ➔ `圆满` (3)
- 前端编写动态推算函数 `getNextRealm(currentRealmStr)`：
  - 若为 `练气期初期`，下一阶为 `练气期中期`（小阶顿悟，成功率 100%，不引雷劫）；
  - 若为 `练气期后期`，下一阶为 `练气期圆满`（小阶顿悟）；
  - 若为 `练气期圆满`，下一阶为 `筑基期初期`（大境界破境，引动九天雷劫，唤起雷劫法会弹窗，进行天命裁决！）；
- 门禁机制：
  - 只有当经验进度达到 100% 时，破境按钮才高亮可用；
  - 若经验未满，按钮灰显锁定，点击时提示：“修为尚未圆满（当前进度 X%），强行引雷恐损道基，请先闭关吐纳或服用灵丹！”。

### 2.2 双轨天命裁决与硬核失败惩罚（选项 B）
- **小阶突破**：
  - 顺畅顿悟，不需要渡劫弹窗，直接完成经脉贯通并提升小阶，真元归零，上限适度提高。
- **大境界引雷渡劫**：
  - 唤起【九天雷劫 · 渡劫问心法会】弹窗；
  - 展示真实当前境界 ➔ 真实目标境界；
  - 支持护心丹药、护法大阵勾选以提升渡劫抗性；
  - **联机模式**：引雷后调用服务端 `/突破`，由后端 `BreakthroughEngine` 驱动 `AIGateway.judge_tribulation`（AI 天命裁决），根据服务端权威回包决定成败；
  - **Demo 模式**：
    - 基础成功率根据目标境界决定（如筑基 65%，金丹 50%，化神 35%）；
    - 勾选丹药 +15%，护阵抵御反噬；
    - 执行真随机判定：
      - **成功**：播放金光大捷弹窗，境界跃迁至新境界初期，增加寿元；
      - **失败（硬核天道）**：播放天雷震颤与【天雷反噬 · 渡劫未果】弹窗，扣除 20% 真元，有 50% 概率折损 1~3 年寿元，并附加【天雷创伤】负面状态提示。

### 2.3 仙鹤机缘与纳戒数据真实落账
- **重构 `ensureDefaultInventory`**：
  - 修复覆盖 Bug：采用 `state.inventoryInitialized` 标记，仅在全局初始无数据时填充基础物品，后续任何操作均持久追加或修改，绝不再重置覆盖；
- **规范仙鹤探路物品结构**：
  - 藏宝图物品类型严格使用 `kind: "treasure_map"`；
  - 补齐 `slotCn: "天机秘宝图卷"`、`archetypeCn`、`coords`、`targetNodeName` 等完整风水定盘字段；
  - 仙鹤衔回的灵石、材料、古卷无损进入纳戒各筛选切片（全部、天机藏图、天材地宝、灵丹妙药）；
- **联机模式纳戒同步**：
  - 接收到服务端物品增加或切换纳戒时，解析后端 `items` / `item_entities` 渲染真实道具。
