# 任务系统 · 设计稿（实现前审阅）

## [S1] Problem

已有 **GoalEngine 六类目标**（可接可拒、机缘向），但缺 **可追踪的指引链 + 明确奖励**：新手不知道「现在该做什么」，日常也缺少「做完一件小事 → 有结果」的闭环。需要 **任务系统** 做指引与奖励，且不能把游戏改成死板主线 RPG。

**定位**：任务 = **指引与赏格**；目标 = **机缘与自由**。二者并存，不互相取代。

---

## [S2] Design

### 2.1 任务 vs 目标（边界）

| | 任务 Task | 目标 Goal |
|---|---|---|
| 形态 | 有序步骤链 / 限时委托 | 可拒、无序、机缘风 |
| 指引 | 强（下一步是什么） | 弱（世间有这些事） |
| 奖励 | **明确规则发奖** | 多为叙事/进度 |
| 数量 | 少而稳（金边） | 可多、可挤占 |
| UI | `/任务` 面板 + 天道盘角标 | `/目标` |

### 2.2 任务类型（首期只做三种）

| 类型 | 代号 | 说明 | 示例 |
|---|---|---|---|
| **入道主线** | `intro` | 每角色一条，教会基础玩法 | 初玩教学 T1–T10 |
| **日常委托** | `daily` | 每现实日 1～2 条，可选做 | 问安/探查/跑腿 |
| **宗门指派** | `sect` | 有宗籍才可见；与宗门令可联动（后置） | 巡山、上交 |

> 不做：冗长主线章节、无限支线树、付费任务。

### 2.3 数据模型（`world_state["tasks"]` + 角色槽）

**全局模板** `TASK_DEFS`（配置/代码表，非 DB）：

```text
{
  id, kind, title, steps: [{id, desc, check: "hook_id", reward:{stones,exp,contrib,merit,items[]}}],
  ttl_h?: number, once_per: "character|day|account"
}
```

**角色进度**（挂 `world_state["task_progress"][user_id|char_id]`，SQLite 可后迁）：

```text
{
  active: [{task_id, started_at, step_idx, done_steps[], meta}],
  done: [{task_id, finished_at}],
  day_key: "YYYY-MM-DD", daily_claimed: []
}
```

### 2.4 步骤检查钩子（规则，不走 AI 判定）

| check | 触发点 | 验收 |
|---|---|---|
| `chat_say` | `/说` 或 `/chat` 发言 ≥N 字 | 任一次即过 |
| `trade_query` | 会话内问货（关键词/意图 trade 且无成交） | 学会「问」 |
| `trade_buy` | 聊天/商会 `do_trade` 成功买入 | |
| `trade_sell` | 成功售出 | |
| `use_pill` | `/服用` | |
| `look_board` | `/天道` | |
| `look_schedule` | `/世情` | |
| `look_echo` | `/望气` | |
| `look_task` / `look_goals` | `/任务` `/目标` | |
| `look_breakthrough` | `/突破` 或 `/目标` 含道途 | |
| `move` | `/go` 迁跃 | |
| `cultivate_done` | `/闭关` 出关结算 | |
| `join_sect` | `/拜入` | 二期 |

钩子只上报 `complete_step(char, task_id, step_id, meta)`；**奖励在 `complete_task` 规则发放**（灵石/修为上限/贡献/功德/物品），与现有 `EVENT_EFFECT_CAPS` 同级钳制。

### 2.5 示例任务包

#### 2.5A 【初玩教学】（intro · 每角色一条 · 约 20～40 分钟）

目标：**用任务把基础玩法教完**，而不是长篇章。每一步 = 学会一个动作 + 明确下一步 + 小赏。

| 步 | 教什么 | 玩家怎么做 | check | 奖励 |
|---|---|---|---|---|
| **T1 识人** | 同场 / 交谈 | 点同场道友，弹窗说一句 | `chat_say` | 灵石 +10 |
| **T2 问货** | 聊天交易 | 问「有什么货」 | `trade_query` | 信息：展示货架 |
| **T3 买卖** | 坊市成交 | 买下聚气丹（或任一货） | `trade_buy` | 聚气丹 ×1 |
| **T4 服药** | 行囊/丹药 | `/服用 聚气丹` | `use_pill` | 修为 +20 |
| **T5 迁跃** | 地图与安全区 | `/go` 任一他处再回坊市（或单次迁跃） | `move` | 灵石 +15 |
| **T6 观照** | 世界与天道 | `/天道` + `/世情` 各一次 | `look_board` + `look_schedule` | 功德 +5 |
| **T7 吐纳** | 修炼闭环 | `/闭关 1` 并出关 | `cultivate_done` | 修为 +40 |
| **T8 渡劫意识** | 突破/寿元概念 | 阅 `/突破`（未圆满则读说明）或 `/目标` 看道途 | `look_breakthrough` | 修为 +30 |
| **T9 望气** | 世界回写 | `/望气` 看凶地/坊市 | `look_echo` | 灵石 +20 |
| **T10 收束** | 任务/目标分工 | `/任务` + `/目标` 各看一次 | `look_task` | 天道小赏 |

**收束文案**（T10 完成）：

> 【天道小赏】初玩既毕：你已识人、行商、迁跃、吐纳、观照天道。此后 **/任务** 为指引与赏格，**/目标** 为世间机缘；二者可并行。庇护尚余约 72 时辰。

**展示规则**：

- `/任务` 只高亮 **当前一步**；可折叠「已学」与「未解锁」  
- 每步完成：动态流一行「已学会：×××」+ 轻量 toast  
- 允许 **跳步检测**：若玩家提前做了买卖，则 T3 直接过并补奖（防逼真走死）  
- 不可弃 intro；超时不做惩罚  

#### 2.5B 【入道速通】（可选，与 2.5A 互斥或并行）

若嫌 T1–T10 偏长，可做 **三步精简版**（原稿）给「直接玩」的玩家；默认仍推 T1–T10。

#### 2.5C 【日常·问安】（daily · 1/日）

与任一 NPC 交谈 ≥2 轮 → 功德 +3  

#### 2.5D 【日常·探风】

`/世情` + 迁跃 2 次 → 灵石 +20

### 2.6 指令与 UI

| 入口 | 行为 |
|---|---|
| `/任务` | 列表：进行中（下一步高亮）/ 可接日常 / 已完成 |
| `/任务 接 <id>` | 接日常/宗门（intro 自动激活） |
| `/任务 弃 <id>` | 放弃（intro 不可弃） |
| `/任务 <id>` | 详情 |
| 工作台 | 天道盘可加「任务」一格（n/3）；**第一晚** 引导改为指向 `/任务`；动态流步进提示 |
| 返回 | `tasks: {active, next_step}` 供前端渲染 |

**文案**：主动动词（「买下聚气丹」），禁止「完成交互行为」式空话。

### 2.7 与现有系统关系

- **GoalEngine**：不动；intro 完成可 `add_opportunity` 一条「机缘未远」作为衔接  
- **宗门令**：`sect` 任务首期只做「登录可见 + 显完成」，奖励可走 `sect_contribution`；完整联动后置  
- **AI**：任务步骤 **不** 用 AI 判定；可在完成时可选一句润色  
- **多开/刷奖**：`once_per`、`daily` 按 user_id+day；奖励钳制  

### 2.8 错误/空态

- 无任务：「世间暂无委托。可先完成【初玩教学】或稍后再来。」  
- 已完成：灰显 + 完成时间  
- 步骤未完成：`/任务` 显示「下一步：…」  
- 接任务失败：明确原因（无宗籍 / 今日已接满 / 不可弃）  

---

## [S3] Out of Scope

- 长篇章主线、剧情树、多结局  
- AI 自动生成任务链  
- 任务交易/拍卖  
- 改写已有 GoalEngine 语义  
- 付费任务/战令  
- **强考题式测验**（教学只引导动手，不考试）  

---

## Acceptance

1. 新号 join 后 `/任务` 含【初入道】且 **下一步** 明确  
2. 完成三步钩子后自动发奖（灵石/丹/修为有账）并标完成  
3. 日常任务每日重置且不可当日重复刷奖  
4. `/任务` 空态/放弃/无宗籍等错误文案可懂  
5. 不破坏现有 `/目标` 与 pytest 回归
