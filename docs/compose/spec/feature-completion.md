## 通用设计约束（所有功能适用）
1. **存档兼容优先**：新状态优先存角色字段（pydantic 新字段带默认值，旧档自动补）或
   `world_state` KV；禁止破坏性改表。必须改表时只加新表。
2. **数值归规则**：一切收益/概率/价格写进 config 常量或新模块常量，AI 只写叙事文本；
   新指令必须同时接入 server/world.py 与 cli/main.py（保持双端一致，有 parity 测试惯例）。
3. **寿元经济闭环**：每个新系统必须回答「烧什么、产什么、与寿元/灵石如何兑换」，
   禁止无成本印钞（对照坊市物价与 EVENT_EFFECT_CAPS 量级）。
4. **网页同步**：玩家主路径指令在 web 加按钮或面板（沿用既有 data-cmd/data-prompt 模式）。
5. **测试**：每项至少 1 个新测试文件覆盖核心闭环 + 边界（无资源、重复操作、死亡/闭关态）；
   全量回归 0 失败才可合并。

## 功能清单与最小闭环（按实施顺序）

### F01 灵宠
捕获（探险/秘境遇兽，规则概率+灵石/丹药成本）→ 契约（限 1 只出战）→ 喂养（灵石/丹药换成长）
→ 助战（斗法/探险小幅加成，走规则）→ 灵宠面板（/灵宠、网页卡）。死亡/放生闭环。

### F02 心法槽位
把现有 skills/自创功法收进槽位制：主修 1 + 辅修 2，装配/卸下指令 /心法；
加成只经规则系数影响修炼效率与斗法（复用 power 体系），切换有冷却（防刷）。

### F03 区域价差跑商
各地坊市同货不同价（按区域系数 + 每日波动，规则生成）；异地买卖即跑商；
路途耗时烧寿元（与世界时钟对齐），冲突区有截货风险（接现有事件/战斗）。

### F04 典当行
物品典当得灵石（约五折），限期赎回（原价+息），逾期没收进坊市流通；/典当 /赎回。

### F05 拍卖专场
在既有 auction_lots 表上补状态机：定时开场 → 出价 → 成交/流拍 → 结算；
NPC 参与出价（规则预算），网页可看当前拍品与出价。

### F06 灵田/洞府经营
洞府落点后开灵田：播种（种子来自坊市/探险）→ 生长（墙钟）→ 收获灵草/灵石；
洞府等级影响田数与闭关加成（小幅、封顶）。

### F07 NPC 委托链
NPC 发布系列委托（2–4 环：送信/寻物/除妖），接取/交付推进链，奖励灵石/声望/功法线索；
与 npc_agendas 共存不冲突，链可中断（超时作废）。

### F08 长老议政
宗门内定期议题（开矿/开战/祭典），长老 NPC 立场由 agenda 推导，玩家可投票/游说
（烧灵石或声望），结果落到宗门状态与世界播报。

### F09 宗门势力版图
区域控制度数据（各宗门在各区域的影响力），由成员活动/议政/除凶累积；
版图影响区域跑商税、坊市价与招募；/版图 可查，网页简图（文本格）。

### F10 炼体/炼神双修
两条副修进度（炼体：抗打/寿元微增；炼神：神识/心魔抗性），资源分别走妖材与悟道类；
与主境界并行不喧宾夺主，数值封顶在 config。

### F11 著书立说
玩家把经历/功法写成书（消耗寿元+灵感来自事件/阅历计数），书入坊市流通、
他人研读得少量修为/道心（一次性），作者得声望；AI 只写书名/序言叙事。

### F12 飞升榜
跨世/跨纪元榜单：按历世最高境界、道统点、坐化年龄等综合排序（区别于现有单世天机榜），
数据来自 player_legacy；/飞升榜 与网页入口。

### F13 纪元天象主题
每纪元（赛季）抽一个天象主题（赤霞/寒潮/灵雨等），全局小幅修正（灵气/事件权重/物价一项），
开季播报、全季可见（命盘/世情），换季轮换；纯规则参数，不改核心数值结构。

### F14 诺言账闭环
补 /许诺 指令：对 NPC/玩家立诺 → 条件达成自动核验或到期判违约 → 因果账落账
（接 karma_links），履约得功德、违约沾业力并入世情播报。

### F15 除凶令状态机收尾
把现有悬赏/功德碎片收成完整状态机：发布 → 接令 → 追凶（定位刷新）→ 围剿（多人同场窗口）
→ 结算；与 F07 委托、悬赏板去重对齐。

### F16 心魔长期状态收尾
把心魔从一次性问答升级为长期状态：心魔种（由血煞反噬/杀业累积）→ 蛰伏/滋长阶段 →
闭关或突破时发作 → 镇压（战斗/丹药/道心）或入魔风险；全程规则数值、AI 只演心魔之言。

### F17 LLM 超时可配置
_chat_json/_chat_text 超时改为 config 常量 + .env 可调（LLM_TIMEOUT_SECONDS，默认 30），
适配慢中转；补 .env.example 与手册说明。（真 AI 实测发现：20s 对中转偏紧。）
