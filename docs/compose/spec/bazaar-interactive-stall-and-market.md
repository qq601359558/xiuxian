# 规格说明：九霄坊市水墨地摊大典与诸天仙商行情 (bazaar-interactive-stall-and-market)

## 1. 痛点问题 (Problem)
- **数据僵化假象**：当前九霄坊市的商品卡片、挂牌件数与收益为静态硬编码文本，道友在纳戒与大荒中获得的珍奇灵材无法自主定价与真实流通；
- **缺乏修仙市井互动**：缺乏小说中生动的“摆摊设坛、挑灯叫卖、散修路过砍价讨价、掌柜竞购”的市井烟火气；
- **经济循环单一**：战利品除了卖给固定系统商会外，缺少动态行情波动与捡漏鉴宝的博弈乐趣。

## 2. 总体设计方案 (Design)
1. **我的坊市地摊 · 聚宝法座 (My Stall & Autonomous Pricing)**：
   - 道友可将百宝纳戒中的灵物（法宝/丹药/灵材/藏宝图）挂牌至自己的地摊（法座上限 8 件）；
   - 自主输入寄售灵石价格（系统给出仙盟建议公允价与浮动参考）；
   - 挂牌灵物从纳戒移至地摊，随时可一键【撤回摊位】（退回纳戒，不收税）；
   - 提供【招徕过往修士】按钮（摇铃传音），主动吸引大荒修士与商贩前来询价；
   - 支持【一键提取灵石】将售出收益划归纳戒。

2. **市井散修与仙商光顾买办 (NPC Customers & Haggling System)**：
   - 摊位会随机迎来各色修仙路人 NPC（如青阳散人、百花仙子、金丹邪修、万宝楼采办）；
   - NPC 行为模式：
     - **豪爽全款买下**：赞叹宝物神异，按标价直接支付灵石买走；
     - **机变砍价讨价**：提出 70%~90% 的折价请求（如：“此图略有残缺，八十灵石可愿割爱？”），唤起水墨还价交互框，道友可选择【成交割爱】或【谢绝还价】；
     - **品评路过**：留下修仙轶事点评后离去。

3. **诸天仙阁寄售行卷与真机交割 (Bazaar Listings & Purchasing)**：
   - 展现动态真实的在售仙物（神兵法宝、保命灵丹、天机秘图、重铸神材）；
   - 支持标签筛选（全部/神兵/灵丹/藏图/神材）；
   - 点击【神念验宝】在鉴真神台展开真实词缀与出处；
   - 点击【立即交割】：严格核验随身灵石与纳戒容量（< 64），支付灵石后仙物即刻进入纳戒首格。

4. **天道行市指数与残宝盲匣捡漏 (Market Index & Treasure Gamble)**：
   - 顶部行市看板展示今日灵材行市涨跌（如纯阳火晶 +12%、避水鲛丝 -5%）；
   - 仙阁特设【古修残宝捡漏匣】：消耗 50~100 灵石购买被封印的锈蚀盲匣，当场在鉴真台解石验真，有概率开出地品甚至天品古宝！

5. **纯正汉字铁律**：全界面 100% 东方水墨古典仙侠风格，严禁英文缩写。

## 3. 不在本次范围 (Out of Scope)
- 跨服务器 WebSocket 实时玩家点对点拍卖会网络长连接（维持本地世界与权威服务状态机）。

## 4. 可独立验收的任务列表 (Tasks & Acceptance Criteria)
- [ ] **Task 1: 后端数据契约与坊市引擎拓展 (`core/market.py`, `server/world.py`)**
  - **验收标准**：支持 `/摆摊 [物品名] [灵石价格]`、`/撤回 [物品名]`、`/收益`、`/买寄售 [序号/UID]`；服务端维护 `stall_items` 与 `market_listings`；纳戒满格拦截与灵石扣除。
- [ ] **Task 2: 前端坊市地摊挂牌与撤回交互 (`web/workbench.js`)**
  - **验收标准**：地摊列表动态绑定道友挂牌物品，支持纳戒中一键跳转挂牌、自主定价；支持撤回退回纳戒、提取收益灵石。
- [ ] **Task 3: 前端市井 NPC 光顾、砍价互动与还价弹窗 (`web/workbench.js`)**
  - **验收标准**：点击【招徕修士】或定时器触发 NPC 来访，弹出水墨议价弹窗，道友可点击【成交割爱】（灵石入收益）或【谢绝还价】。
- [ ] **Task 4: 诸天寄售行卷交割与残宝盲匣解石捡漏 (`web/workbench.js`)**
  - **验收标准**：商品行卷点击交割扣减灵石并入纳戒；盲匣购买后播放解石动效并爆出随机仙物。
- [ ] **Task 5: 后端单元回归测试 (`tests/test_trade_hub.py`, `tests/test_bazaar_interactive.py`)**
  - **验收标准**：所有测试通过，覆盖摆摊、买入、撤回、满格拦截。
- [ ] **Task 6: Playwright 端到端真机验收 (`scratch/verify_bazaar_interactive.py`)**
  - **验收标准**：完成摆摊挂牌、NPC 砍价成交、寄售购买、盲匣捡漏全链路，输出真机截图。
