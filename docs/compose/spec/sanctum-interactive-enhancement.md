# 规格说明：九天碧虚洞府全套按钮交互与沉浸式体验完善 (sanctum-interactive-enhancement)

## 1. 痛点问题 (Problem)
- **痛点一（按钮失灵假象）**：前端演示模式下，`demoResult` 未产生任何 `status` 变更，点击闭关状态不变、金库不划转、引雷破境不动，导致用户直观感觉“按钮似乎都不能用”；
- **痛点二（后端回包契约缺陷）**：在 `server/world.py` 中，`_meditate`、`_emerge`、`_deposit`、`_withdraw` 返回字典缺少 `"status": self._status_dict(c)`，真实联机时前端同样无法即时刷新灵石与状态；
- **痛点三（指令错位与语义割裂）**：紫菁草园【采摘灵草】误绑 `/帮助 丹药`，镇山仙鹤【命灵鹤探路】误绑 `/秘境`，玄冰灵泉【提取灵露】误绑未注册指令 `/修炼`；
- **痛点四（缺乏修仙沉浸仪式）**：引雷破境无渡劫契约与雷劫动效，仙鹤探路无神识罗盘与远巡轻倒计时，灵泉汲取与药园采摘无收菜即时反馈。

## 2. 总体架构与设计方案 (Design)
- **双轨权威闭环**：
  1. **前端交互与视效层 (`web/workbench.js`, `web/workbench.css`)**：
     - 构建水墨白玉通微弹窗机制 (`openJadeDialog`)；
     - 引入专属洞府行为路由 (`data-sanctum-act="spring|herbs|crane|breakthrough|meditate|emerge|vault|astro"`)；
     - 深度拟真 Demo 模式状态机：灵泉充盈度、草园成熟度、仙鹤巡弋倒计时、金库随身灵石双向流转、修为增长、纳戒道具入库真实落账；
     - 引雷破境大典：天劫成功率、避雷丹药/护阵勾选、屏幕震颤天雷动效、心魔问心分支、升阶金光；
     - 闭关吐纳态：道身立绘周围环绕聚灵青岚流光动效，按钮动态平滑切换为金色【收功出关 (已入定 X 刻)】，收功结算弹窗；
     - 仙鹤八荒探路：轻度 15~20 秒远巡倒计时，归巢带来机缘残图；
  2. **后端服务协议层 (`server/world.py`)**：
     - 闭关、出关、寄存、支取回包统一补齐 `"status": self._status_dict(c)`；
     - 注册/适配 `/灵泉`, `/草园`, `/灵鹤` 等洞府设施指令，保持真机与离线心智严格统一；
- **纯正汉字铁律**：全部弹窗、按钮、动效飘字、日志输出 100% 纯正简体中文水墨仙侠语境，严禁任何英文生硬缩写。

## 3. 不在本次范围 (Out of Scope)
- 坊市寄售的跨服拍卖行情图谱重构（维持现有坊市逻辑）；
- 大荒战斗引擎 AI 提示词与大模型网关协议重构（维持现有战斗体系）。

## 4. 可独立验收的任务列表 (Tasks & Acceptance Criteria)

- [x] **Task 1: 后端 `server/world.py` 回包契约修复与洞府设施指令支持**
  - **验收标准 (AC1)**：`/闭关`、`/出关`、`/寄存`、`/支取` 返回体必定包含有效 `status` 字典；新增设施指令支持，单元测试全部通过。
- [x] **Task 2: 前端水墨弹窗框架与动效样式 (`web/workbench.css`)**
  - **验收标准 (AC2)**：引入雷劫天威震颤动画 (`@keyframes thunderShake`)、聚灵法阵青气流转动画 (`@keyframes meditatePulse`)、灵水汲取飘字动效；纯汉字提示。
- [x] **Task 3: 前端洞府交互控制器与双轨状态落账 (`web/workbench.js`)**
  - **验收标准 (AC3)**：
    - 点击【入定闭关】立即可见吐纳流光，按钮切换为【收功出关】；点击【收功出关】弹出结算弹窗，真元增加；
    - 点击【引雷破境】唤起天道雷劫问心大典弹窗，备战策略可选，引雷后播放天雷动效与结算；
    - 点击【提取灵露】充盈度清零并进入蓄水，获得【玄冰玉露】入纳戒，飘字真元暴涨；
    - 点击【采摘灵草】唤起草圃弹窗，支持灵石催熟与仙草采摘，得【千年紫菁芝草】入纳戒；
    - 点击【命灵鹤探路】唤起巡弋八荒罗盘，仙鹤进入 20 秒倒计时远巡，归巢送出藏宝机缘；
    - 点击【存入百石】/【支取百石】随身灵石与金库储积数字实时联动增减；
    - Demo 离线与 Live 在线双轨表现完全一致。
- [x] **Task 4: 全套回归验证与无头渲染校验**
  - **验收标准 (AC4)**：通过现有测试套件（pytest），无头渲染生成洞府闭关、渡劫、仙鹤远巡各状态截图，验证视觉无瑕疵。
- [x] **Task 5: 仙鹤探路灵石扣减与纳戒机缘可见性全链路闭环 (crane-stones-and-inventory-fix)**
  - **验收标准 (AC5)**：
    - 仙鹤巡弋阶梯扣费：落霞密林 10、黑风绝渊赤焰 30、南海碧波古墟 50 灵石，随身灵石精确扣除并阻断余额不足；
