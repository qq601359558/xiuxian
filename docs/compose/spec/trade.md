# F03 区域价差跑商 Spec

> 上位文档：docs/compose/spec/feature-completion.md（F03）。基线：f6687fb（全量 279 passed）。
> 创作者已授权「直接改、无需逐项确认」，本 spec 即阶段一细化结论（requirement-evaluator 五步收敛）。

## 需求本质与核心诉求
- **表层需求**：各地坊市同货不同价，玩家低买高卖跑商获利，新增 /行情 一览价差。
- **本质意图**：给灵石经济加一条「空间套利」循环——让 /go 迁跃、区域分布与坊市价格联动，
玩家的时间与路线选择产生收益；同时给探险/斗法之外的和平收入线（量级受控，不碾压既有收益）。
- **关键目标**：区域价单点收敛、双端同价；低买高卖闭环可玩通且利润有封顶；
同货同日反复套利被规则压回归；旧坊市行为在基准区逐字不变。

## 现状盘点（实测，2026-11-04）
- **价格体系**：`config.ITEM_CATALOG`（21 件，kind/price 单价全国统一）；
`MarketEngine.buy_from_guild` 按标价卖、`sell_to_guild` 按标价 ×`MARKET_SELL_BACK_RATE=0.5` 回收；
寄售是玩家定价（本项不碰）。NPC 专柜（NpcShopEngine）是另一套，不碰。
- **地点体系**：`WORLD_LOCATIONS` 10 个地点（含 2 别名）分属 4 区域：
东荒·青州（坊市客栈/青云宗山门/玄元洞府/落霞山灵泉）、中土·万岳（万剑峰/洗剑池）、
西陲·幽冥渊（天魔宗坛/黑风绝渊）、海外·乱星海（万星古岛）。每地点有 region/is_safe。
- **迁跃口径**：`/go` 即时抵达，**无直接寿元/时间成本**；成本在路途风险——
`_go` 落点即掷 `EventEngine.fire`（危机池含「劫修拦路」破财）、奇遇链、因果回访（仇家截道）。
本项沿用此口径，不新增时钟成本（见决策 3）。
- **价格锚点（既有测试钉死，回归红线）**：默认出生地青云坊市客栈（青州）下，
聚气丹买价 40、一阶青木迷踪阵买价 120、妖兽内丹回收 40（=80×0.5）必须逐字不变
（tests/test_market.py、tests/test_env_time_scale.py）。
- **落账惯例**：server handle 成功才 `CharacterRepository.save`；引擎失败不改状态
（sell 的「成功才落库」由 handle 保证；buy/sell 引擎内先校验后扣账）。

## 关键设计决策（与备选对比）
1. **价格模型：基准区锚定 + 产地/距离系数 + 每日波动（纯函数）**。
- 青州是四海散修商会总号所在地，定为**基准区**：区域系数恒 1.00、无每日波动——
标价即青州价。既有锚点测试天然全过，且「标价」一词从此有明确语义。
- 其余区域：货物有**产地**（config `TRADE_ITEM_ORIGIN`，21 件全覆盖）；
在产地系数 0.55（产地直供价）；在其他区域按与产地的**区域距离**加价
（距离 1/2/3 → 系数 1.05/1.20/1.35）；青州产货物在外埠同样按距青州距离加价。
- 每日波动：非基准区系数再乘 (1 ± 3%)，由 (日期, 区域, 货物) 的 md5 种子确定性生成——
全服一致、可复现、零存储（纯函数，不落 world_state；日期取本地日期）。
- 备选「波动落 world_state 每日生成」否决：纯函数同等一致性且无状态污染、无跨日清理问题。
- 备选「每区域独立系数表（21×4 手工填）」否决：产地+距离可由少量常量推导，易校准易扩展。
2. **买卖同价锚**：买入价 = round(标价 × 区域系数)（即当地「市价」）；
回收价 = max(1, int(市价 × MARKET_SELL_BACK_RATE))，与现行「回收=买价五折」口径一致，
只是买价换成区域市价。套利成立条件：卖出区系数 > 2 × 买入区系数——
仅产地（0.55）→ 远方（1.20/1.35）路线成立，单程毛利率结构封顶：
距离 2 路线 (1.20×0.5)/0.55−1 ≈ 9%；距离 3 路线 ≈ 23%（含双边波动与取整的最坏情形 ≈ 31%，
由 tests/test_trade.py 遍历 90 天实测钉住）。
基准区货物（系数 1.00 买入）卖到任何区域回收 ≤ 0.675×标价，**结构性不可套利**，
它们是消费品而非跑商货——行情板会如实呈现哪些货有跑商路线。
- 校准对照：探险单次收益量级（盘缠 20、事件灵石增益上限 300）；
跑商带货 10 件距离 3 路线，毛利约 10×0.55×标价×0.23，标价 200 的货约 +250，
与一次好探险相当，且还要吃防刷回归与路途风险，不碾压。
3. **迁跃成本沿用现状**：不给 /go 新增寿元/时间成本（动世界时钟口径属核心数值变更，
超出本项范围）；跑商的成本 = 路途事件风险（既有危机/截道）+ 防刷回归 + 资金占用。
冲突区截货：现有 _go 落点事件（危机池「劫修拦路」即截货）已覆盖，本项不新造战斗/事件，
只在 spec 注明挂接点为既有 EventEngine/RevengeEngine。
4. **防刷：单角色同货同日收购量回归（价格回归）**。
商会对同一修士同一货物有「日收购配额」：当日累计收购量进入分档压价——
前 10 件全价、第 11–20 件 ×0.8、第 21–30 件 ×0.6、30 件后 ×0.45（单件逐件计价，
一次大额出售自动跨档结算）。状态存 world_state（key=`trade_reg:<char_id>`，
{date, vol:{item:qty}}，跨日自动重置）。
- 选此而非「全服行情回归」：全服量会让测试与玩家互相污染价格、且需要清理策略；
单角色口径同样达成「同货同日不可无限刷」，且与既有测试零冲突（各测试角色独立）。
- 买入侧不回归：商会卖货库存深，套利提取端在卖出侧，回归落在卖出侧即封口。
5. **区域取价的位置口径**：价格按**角色当前地点**的 region 计算（buy/sell/catalog 统一）；
地点不在 WORLD_LOCATIONS 时回退基准区系数 1.00（野外别名等异常坐标不炸）。

## 完善后的规则闭环（行为契约）
### 常量（config.py，坊市一节后新增「区域跑商」节）
- `TRADE_HUB_REGION = "东荒·青州"`
- `TRADE_ORIGIN_FACTOR = 0.55`
- `TRADE_DISTANCE_FACTORS = {1: 1.05, 2: 1.20, 3: 1.35}`（距产地距离 → 系数；同区非产地不适用）
- `TRADE_DAILY_FLUCTUATION = 0.03`
- `TRADE_ITEM_ORIGIN: Dict[str, str]`（21 件全覆盖：剑器/阵盘多产万岳，妖材产幽冥渊，
遗迹货产乱星海，丹药/灵草/符佩产青州）
- `TRADE_REGION_DISTANCE: Dict[frozenset, int]`（4 区域两两距离 1–3）
- `TRADE_REG_TIERS = [(10, 1.0), (20, 0.8), (30, 0.6), (inf, 0.45)]`（累计件数上限 → 回收价系数）
- `TRADE_REG_STATE_PREFIX = "trade_reg:"`（world_state key 前缀）

### 引擎（core/market.py · MarketEngine 扩展，价格单点收敛）
- `region_of(location) -> str`：WORLD_LOCATIONS 查 region，缺失回退基准区。
- `regional_factor(item_name, region, day=None) -> float`：基准区恒 1.0；
产地 0.55；其余按距离查表；青州产货物按距青州距离；未知货物 1.0；非基准区乘每日波动。
- `market_price(item_name, location, day=None) -> int`：max(1, round(标价 × 系数))；无目录货物回退现行默认 20。
- `buy_price/sell_unit_base` 语义并入 buy/sell：buy_from_guild 用 market_price(char.location) 计总价
（消息注明当地市价与产地提示）；sell_to_guild 用「市价 × 0.5」为单件基准价，
再按当日收购量分档逐件计价，返回 gain 与分档明细（均价、是否压价）。
- `catalog(location=None)`：不传地点时与现行完全一致（标价）；传地点时 price 为当地市价，
并附 `base_price / origin / factor / sell_price` 字段供双端呈现。
- `trade_board(location=None) -> str`：/行情 文本——逐区域列主要货物当地价，
标注与相对基准区的涨跌幅，并给出今日可跑路线提示（产地→高价区，本地模板文本，零 AI）。
- 收购量状态：`_reg_state(char_id)` / `_reg_record(char_id, item, qty)` 走 WorldStateRepository，
读写失败时降级为无回归（try 包裹，不阻断交易，与仓库既有容错惯例一致）。

### 指令（server/world.py 与 cli/main.py 双端一致）
- `/坊市`：货单价改为当地市价，标题行带当前区域；产地货标「产地价」，高价货标涨幅；
底部加一行行情提示（/行情 看全域价差）。
- `/购买`、`/出售`：签名不变，价格自动按区域走；成交消息含当地价信息。
- `/行情`（新）：输出 trade_board；只读，**双端闭关白名单**（server med_ok 与 cli 白名单均加，
与 CLI 既有 /坊市 可观照口径一致）。
- server 帮助行、cli 帮助行各加 /行情 一行。

### 网页
- web/index.html 仙门·坊市卡加「行情」按钮（data-cmd="/行情"），仅此一处；
/坊市 与 /行情 的区域价文本走既有日志区呈现，前端零逻辑改动。

## 边界与异常
- 灵石不足：沿用现行校验，报错含当地单价与所需总额。
- 无货出售 / 无目录货物：沿用现行（无目录按默认价 20、系数 1.0 参与回收与回归）。
- 死亡角色买入：现行 buy 在扣款后才查 DEAD 是既有顺序问题，本项不顺手改（Out of Scope 记录）；
本项新增路径不得引入新的「先扣后验」。
- 闭关中：/购买 /出售 仍被既有门禁拦截（不在白名单）；/行情 只读放行。
- 别名地点（落霞山灵泉(野外）等）region 与本体一致，价格同区同价。
- 跨日：波动与收购量均以本地日期为界自动切换，无需任何定时任务。

## 验收标准
1. tests/test_trade.py 新增用例覆盖：区域价差异与确定性（同日同货同区同价、纯函数可复现）、
产地价 < 基准价 < 远方价、低买高卖闭环获利且单程毛利率 ≤ 封顶（距离 3 路线结构 22.7%、含波动取整 ≤ 31%）、
波动按日不同、防刷回归生效（同货同日大量出售单价递减、总收益被压）、
灵石不足/无货边界、server handle 全链路（/行情、异地 /购买→/go→/出售）、
基准区锚点（青州买/卖价与旧口径逐字一致）。
2. 全量回归 0 失败（基线 279 + 新增）。
3. 独立评审子代理审 diff，必须修项整改后复跑全量。

## Out of Scope
- 寄售/拍卖/NPC 专柜价格（玩家与 NPC 体系，本项只动商会官价）。
- /go 新增时间/寿元成本、新截货战斗或事件（沿用既有路途事件）。
- F09 势力版图对区域税/价格的影响（版图未建，系数表预留为 config 常量可叠加）。
- buy_from_guild 死亡校验顺序等既有问题（另行记录，不在本项顺手改）。
- 货物产地/距离数据的动态变化（本项为静态配置 + 每日小幅波动）。
