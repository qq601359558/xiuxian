# 仙途水墨翡翠工作台：纯汉字正统修仙前端重塑 (Vertical Slice)

## Problem
1. 当前 Web 前端（`web/index.html`, `web/workbench.css`, `web/workbench.js`）为简陋的黑底白字运维控制台风格，视觉缺乏修仙意境；
2. 上一阶段完成的 `Core-V2 Reborn` 换心重构（实体装备 `ItemEntity` 随机词缀、空间拓扑路网、世界疤痕、实体藏宝图干支五行解谜、20灵石探险保底与寄售流转）缺乏可视化呈现，用户只能看到粗糙的纯文本打印；
3. 之前原型生成中混杂了英文代码标签（如 `Sanctum`, `Inventory`, `Slot 1`, `Node X Y`），严重破坏正统东方仙侠沉浸感。

## Design
基于已锁定的 `Ethereal Jade Cultivation` 水墨翡翠白玉仙侠设计体系，以**「黄金核心循环垂直切片」**自顶向下重构工作台前端：

1. **设计 Token 与白玉微透体系 (`web/workbench.css`)**：
   - 提取配色变量：羊脂白玉背景 (`#f2fcf4` / `#fbfcf9`)、冷杉墨青 (`#1a4a40` / `#146a59`)、帝王古金细丝 (`#c5a059` / `#d4af37`)、松烟水墨 (`#404944`)；
   - 磨砂玻璃质感（Backdrop Filter Blur）、微倒角切面与八角法宝格；
   - 东方古典排版：宋体/楷体衬线字韵，舒展诗意字距；
   - **绝对硬性规则**：全界面 100% 纯简体中文，严禁任何英文字母、西式缩写或拉丁符号。

2. **四大核心主循环导航与天道盘 (`web/index.html`, `web/workbench.js`)**：
   - 顶部天道盘：修士道号、境界品阶、气血/神识状态、下品灵石与仙金资产；
   - 核心四大主境导航：
     - **【玄阁洞府】**：道身观照、气机吐纳打坐、日常任务指引、洞府门楼；
     - **【十方大荒】**：四大秘境画卷（野外山原、落霞古洞、黑水沼泽、万星遗迹），20 灵石盘缠消耗，初探 100% 必得藏宝图金印，梯度危险度，世界疤痕赤焰火海警报，大荒历练实纪卷轴；
     - **【百宝纳戒】**：三大本命槽位佩戴（本命法宝、随身灵兵、护身灵宝），八角芥子储物格，万象灵宝鉴真（完整展示 `ItemEntity` 的破煞/嗜血/固元/凝神词缀、完好耐久、天干地支五行藏宝图）；
     - **【九霄坊市】**：商会买卖、金库寄存取回、5% 契税玩家摆摊与寄售、神念验宝与立即交割。

3. **江湖神识抽屉与 MUD 灵魂台**：
   - 右侧可收折式「同场仙友神识感应浮匣」：查看当前同场修士/NPC（青阳散人、云瑶仙子、通缉恶徒），支持即时交谈、当面交易、除凶告示与切磋斗法；
   - 底部神识敕令台：保留模糊指令搜索与自由言行意图判定（`/做`），兼顾纯鼠标点击与文字修仙精髓。

## Out of Scope
- 3D WebGL 复杂模型渲染；
- 原生 iOS/Android App 打包。
