# 规格说明：十方大荒秘境探险奇遇与动态遭遇战闭环 (wilderness-adventure-encounter)

## 1. 痛点问题 (Problem)
1. **交互断层与白板感**：大荒界面虽然具备四大秘境高保真水墨画卷与危险度指标，但点击各秘境下的【启程赴险】按钮时，仅在控制台/信息流输出一行简短文本，缺乏任何视觉交互与探险仪式感；
2. **离线状态脱节**：Demo 模式下探险未实际扣减 20 灵石盘缠、未增加真元、未掉落任何真实道具入库纳戒，新秀首探 100% 必得藏宝图的保底机制在离线端悬空；
3. **门禁校验缺位**：当随身灵石不足 20 时、角色尚在闭关入定中时、或者练气初阶修士涉足天阶绝境时，未在前置交互中进行合理拦截与友好警示；
4. **探险到寻宝链路断裂**：探险获得藏宝残图后，缺少直接导向【百宝纳戒 · 天机藏图】切片的快捷检视入口。

## 2. 总体架构与设计方案 (Design)

### 2.1 门禁校验层 (Gate Protection)
在发起探险前进行前置裁决：
- **盘缠校验**：若随身灵石不足 20，弹窗/浮动提示：“囊中羞涩（当前仅余 X 灵石），探险需备足 20 灵石盘缠，请先至坊市或金库支取！”；
- **闭关阻断**：若角色处于闭关状态（`is_meditating: true`），拦截并提示：“道友洞府大阵锁闭、正值五心朝天入定吐纳，不可强行外出！请先收功出关。”；
- **境界警示**：若涉足危险度极高的绝境（如【万星遗迹残址】），若境界低于筑基期，给予“绝境煞气惊悸”提示，允许道友确认是否冒险一搏。

### 2.2 水墨大荒探险大典控制器 (`handleWildernessAdventure`)
点击四大秘境（野外山原、落霞古洞、黑风绝渊、万星遗迹）的【启程赴险】按钮，统一路由至专属水墨大典：
1. **阶段一：破云寻幽 (Cloud Journey)**
   - 唤起水墨白玉通微弹窗 (`openJadeDialog`)，全景展示秘境画卷、凶险程度与灵气稀释因子；
   - 消耗 20 灵石盘缠，展示云雾缭绕动效；
2. **阶段二：妖兽突袭与奇遇突变 (Encounter & Combat)**
   - 随机抽取秘境契合的妖兽或远古禁制：
     - 野外山原：【白额青鬃兽】（凡阶，攻伐微弱，擅采灵草）；
     - 落霞古洞：【守洞玄猿】（玄阶，手握石棍，守护玉泉）；
     - 黑风绝渊：【九幽冥风蝠】（地阶，尖啸裂魂，伴生阴晶）；
     - 万星遗迹：【太古剑煞傀儡】（天阶，残存剑意，凶戾无匹）；
   - 展示妖兽水墨印记、战力评估与斗法激荡（`combat-clash` 剑气与法宝碰撞动效，历时约 1.2 秒）；
3. **阶段三：天道裁决与战利品结算 (Tribulation & Loot Settlement)**
   - **双轨裁决**：
     - 联机模式：向服务端发送 `/探险 <秘境名>`，解析后端权威回包中的 `adventure` 字段与 `status` 字段；
     - Demo 模式：结合角色境界、秘境危险度（22%~75%）与首探保底规则进行真实随机判定；
   - **战胜结算**：
     - 真元大幅精进（随秘境凶险度递增 150 ~ 1,200 点）；
     - 拾得灵草、丹药或法宝一件；
     - **藏宝残图掉落**：首次探险 100% 保底掉落【天机秘宝藏宝残图】（后续依危险度 8%~40% 梯度概率掉落）；
     - 所有战利品真实追加至 `state.inventory` 纳戒首位，并持久落账；
     - 弹窗呈现【天道机缘 · 凯旋大捷】结算面板，包含【前往百宝纳戒查验】快捷入口；
   - **败退结算**：
     - 护体罡气震散，负伤狼狈遁回；
     - 扣除少量真元与气血，提示“温养疗伤，稍后再探”。

### 2.3 纯正水墨仙侠视效与纯汉字铁律
- 严格遵循 100% 纯正简体中文水墨仙侠语境，严禁任何英文缩写；
- 适配 CSS 样式：新增斗法剑光震颤 (`@keyframes combatClash`)、仙光破阵辉芒 (`@keyframes victoryGlow`)。

## 3. 不在本次范围 (Out of Scope)
- 宗门跨服领地战体系；
- 复杂的 3D 渲染动画（坚守轻量雅致 2D 水墨白玉宣纸质感）。
