# 天道导演 · 端到端验收清单

> 用途：用真 AI（或本地降级）验证「AI 主导走向」是否可感知。  
> 配置：`.env` 的 `LLM_API_KEY` / `LLM_API_BASE` / `LLM_MODEL`；测试降级设 `ALLOW_LOCAL_AI=1`。

## 0. 通道与链路

| 步骤 | 操作 | 期望 |
|---|---|---|
| 0.1 | 启动 `python -m server.run`，进游戏 | 能 join |
| 0.2 | `/ai` | 对话测试成功；**天道导演链路**各项多为 ✓ |
| 0.3 | `GET /world/director` 或网页世间页态势卡 | 有 JSON / 卡片 |

## 1. 天道推演

| 步骤 | 操作 | 期望 |
|---|---|---|
| 1.1 | `/天道 推演` | `来源` 为服务器 AI（非仅 local）；有 0～3 条指令 |
| 1.2 | `/天道` | 能看到活跃指令与叙事；非法效果不会出现修为/灵石直改 |
| 1.3 | 连续推演 2～3 次 | **类型不全是 omen**；有世界态势时应出现血煞/宗门/秘境/宗门令等（`ai+world` 补种也算） |
| 1.4 | 无 Key 且 `ALLOW_LOCAL_AI=0` | 明确不可用，不假装成功 |

## 2. 世界跟着变

| 步骤 | 操作 | 期望 |
|---|---|---|
| 2.1 | 推演后 `/世情` 或 `/世界演变` | 摘要含天道/弧/势力/望气等 |
| 2.2 | `/世界弧` | 若有升格弧，能看到阶段 |
| 2.3 | `/势力` `/宗门令` | 有关系/围剿/令（世界演进后） |
| 2.4 | `/望气` | 出现凶地/恐慌时有数字 |
| 2.5 | `/目标` | 可能出现天道/机缘相关目标（可拒） |
| 2.6 | `/频道` | 导演/弧/围剿播报 |

## 3. 玩家行为回写（手动）

| 步骤 | 操作 | 期望 |
|---|---|---|
| 3.1 | 野外 `/斗法` 连斩（或脚本造业力） | `/望气` 区域危险上升；`/坊市` 买价可能上涨 |
| 3.2 | `/look` | 可能有凶名/望气条 |
| 3.3 | 接 `/除凶` 并 `/接除凶` | 完成令有功德；榜面可能有压力提示 |

## 4. 史笔回流

| 步骤 | 操作 | 期望 |
|---|---|---|
| 4.1 | `/纪元回流` | 有活跃权重（造传说/弧决算/大劫后更明显） |
| 4.2 | `/传说` | 史笔 + 回流摘要 |
| 4.3 | `/天道 推演` | 简报/提案会提到史笔余势（`ai+era` 补种亦可） |

## 5. 网页

| 步骤 | 操作 | 期望 |
|---|---|---|
| 5.1 | 世间页「世界演变态势」卡 | 数字/摘要刷新 |
| 5.2 | 按钮：天道/势力/望气/世界弧/纪元回流 | worldBody 有对应文本 |

## 已知边界

- AI **不**直接改胜负/灵石；效果过门禁。  
- 无 AI 时拒绝或标注 local，不伪造成天道裁决。  
- `test_events_ai` 依赖外网探测，偶发超时与提案质量无关。
