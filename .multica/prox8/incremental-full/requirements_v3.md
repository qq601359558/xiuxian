## 0. 摘要 / 游戏总览 / OQ 收敛结论 / 质量评分 / 修订溯源

### 0.1 摘要（3 句）

1. 我们做一款 Steam（PC）联网多人修仙游戏：以「修仙世界模拟」为骨架、AI 生成事件与角色言行，把修仙网文「一世道途 + 天道无情」的核心体验做成**规则本身**——寿元按现实时间结算（游戏内 1 年 ≈ 现实 1 天）、零和资源、因果业力、天劫心魔都是机制而非文案。
2. 给修仙网文读者与国产修仙/模拟经营玩家；商业模式为买断本体 + 付费货币「仙晶」内购 + 月票 DLC（D6 所述"内购灵石"在本版细化为灵石/仙晶双币，见 §0.5/FR-8）；AI 消耗以游戏内货币包装、后端按 token 折算，**玩家界面永不见 token 与计费感知**（D4）。
3. 以「共享大世界、玩家互为内容、赛季轮回、世界记住你」做差异化；赛季制封顶单账号成本、给"无固定结局"的沙盒提供方向性目标与排行结算锚点（D5/D7）。OQ1（强 PvP + 天道自平衡 + 三护栏）与 OQ2（标准服 12 现实周）已由创作者确认（2026-09-09，见 §0.3）。

### 0.2 游戏总览（给创作者）

> 本节用非技术语言概述本作，供创作者快速建立整体认知。细节以各技术章节为准：玩法验收见 §4，功能见 §5，目标与任务形态见 §6。

**① 整体内容：这是什么游戏**

一款在 PC/Steam 发行的**联网多人修仙模拟游戏**。玩家扮演一名修士，在一个**共享的大世界**里修炼、历练、结盟、争斗，经历"一世"的降生与陨落。修仙网文里"一世道途、天道无情"的设定被做成**真实规则**：寿元会倒计时、灵气总量有限、滥杀会积累业力、渡劫可能失败陨落。

世界的所有数值与因果由**规则引擎**裁决（战力、渡劫成败、财货归属、业力功德），由 **AI** 负责让世界"活"起来（生成事件、NPC 言行、秘境奇遇、渡劫叙事）。玩家永远不会看到 token、计费等后端概念。

商业模式：买断本体 + 小额付费货币「仙晶」内购 + 月票 DLC；并提供免费试玩额度，足以体验一世前期（详见 §10 与 FR-11）。

**② 玩法：一世循环 + 多人世界**

- **一世循环**：降生 → 修炼 / 历练 / 坊市 / 结交 / 争斗 → 突破渡劫 → 面对寿元大限 → 陨落或飞升 → 转世（携带道统点与传说进入下一世）。没有"通关"；每世的目标由玩家与世界共同生成。
- **多人世界**：所有玩家共享同一界。**灵气总量有限**——高阶修士越多，全服修炼越慢，世界天然产生竞争。玩家之间**可动手、可杀人夺宝**，但不是无法无天：滥杀者积累**业力**，会被天道标记（天机显影），引来天劫加强与"除凶"猎杀。这就是**天道自平衡**：冲突强度由机制调节，不需要运营用版规镇压。
- **三护栏**：新手庇护（72 小时）、安全区（坊市 / 宗门驻地 / 秘境入口周边）、离线庇护（需脱战并身处非冲突区后离线，或主动「闭关归隐」；斗法中直接下线按「逃遁失败」结算）。离线可挂机闭关修炼，收益有上限。
- **赛季轮回**：一服一界，一个赛季（标准档 **12 现实周**）= 一个「纪元」，以**天地大劫**收尾；未飞升者转世进入新纪元，世界以"传说 / 典籍 / 遗迹"记住上纪元的事迹。

**③ 境界级别一览**（示例刻度，最终数值由数值策划校准，见 FR-3）

| 境界 | 破境方式 | 累计寿元（示例，岁＝现实天） | 玩家体感 |
|---|---|---|---|
| 凡人（入世） | — | 出生随机 **70–100** | 开局，命数已定 |
| 练气 | 引气入体 | 约 80–120 | 入门、法术初成 |
| 筑基 | 渡劫 | 约 100–160 | 第一次渡劫 |
| 金丹 | 渡劫 | 约 140–240 | 结丹立基 |
| 元婴 | 渡劫 | 约 220–390 | 元婴出窍 |
| 化神 | 渡劫 | 约 370–690 | 神识大成 |
| 炼虚 / 大乘 | 渡劫 | 区间继续放大 | 大能之境 |
| 渡劫（飞升判定） | — | 飞升后不再受寿元约束 | 纪元终局的个人飞升分支 |

**寿元规则（创作者确认 2026-09-09）**：入世时凡人之躯寿元随机（示例 70–100 岁）；此后每渡过一次大境界天劫，按区间**随机增寿**（示例区间见 FR-3）；同一大境界内小阶晋升主要加修为/实力、**不加寿元**。寿元按现实时间流逝（**1 游戏年 = 现实 1 天**），登录与否都扣——"大限"是本作最核心的决策压力，延寿宝/道体/功德可再叠加。每大境界含 3 小阶。

**④ 任务与目标形态：无主线、无任务清单**

本作**没有固定主线、没有任务清单、没有每日打卡**。目标感来自六类**目标源**（详见 §6），全部**可接可拒、有后果**：

1. **一世道途目标**——境界推进、延寿、飞升；
2. **机缘与事件**——AI 生成的事件链、秘境、天机推演；
3. **悬赏与复仇**——被害者挂赏、猎手接令；
4. **宗门与师门**——俸禄、传功、道统；
5. **赛季大目标**——应对天地大劫，飞升或转世收尾；
6. **新手引导线**——免费额度「初入道」内的目标：练气 → 首次筑基渡劫（72h 庇护期内）。

系统以「机缘 / 卦象 / 告示」的形态推送目标：拒绝不惩罚、错过还有机会；新手引导以目标进度呈现，不以任务清单驱动。

### 0.3 OQ 收敛结论（**创作者已确认 2026-09-09**）

> **状态升格声明**：OQ1、OQ2 已于 **2026-09-09 由创作者在父 issue WS-155 评论区确认采纳**（OQ1＝强 PvP + 天道因果自平衡 + 新手/安全区/离线三护栏；OQ2＝标准服 12 现实周及配套双时间轴 + 托管规则）。本节由「草案 / 待确认」升格为「**已定**」，是阶段三评审与架构/开发引用的权威口径。对应 A/B/C 拍板项在 §12 同步标「✔已定」。

**OQ1 · 玩家互动/PvP 强度与形态 —— 已定为「强 PvP，可动手，天道自平衡」**

| 维度 | 收敛结论（已定） |
|---|---|
| 强度档 | **HARD（硬核）**：全域多数场景可互相动手、可杀人夺宝；不提供"开/关 PvP"开关。 |
| 约束来源 | 不用版规管冲突，用**天道因果自平衡**机制约束（滥杀 → 业力 → 天劫/心魔/被天道标记 → 人人可诛），D8 成立。 |
| 护栏边界（A-1 修订，已定） | ① 新手庇护：新账号现实 72h 且境界 ≤ 筑基初，不可被攻击、不可主动伤人（对称设计，防小号骚扰）。② 安全区：坊市/宗门驻地/秘境入口周边为「不可动手区」。③ 离线庇护（修正，不再"一离线即庇护"）：仅当**已脱战且身处非冲突区后离线**，或**主动「闭关归隐」**，才进入庇护；庇护中不可被攻击、随身不可被夺，但**庇护期间随身财货不可交易/转移**（防"下线=保险库"）。④ 即时下线不豁免：斗法中或冲突区直接下线**不视为入庇护**，由规则引擎按「逃遁失败」结算（斗法中→判负可被夺；冲突区非斗法→记「仓皇遁走」遗财折损，不伤性命；见 FR-6）。强制攻击真正庇护对象仍受天道直接降罚（业力暴涨 + 天机显影）。 |
| 夺宝边界（A-2 修订） | 只夺「未绑定」随身财货；神识绑定法宝/道印之物不可掉落；单次击杀收益有上限、单日击杀收益递减（配合 D9）。**坊市寄存 = 安全存放/离线前安置财货的标准路径**（收保管费，寄存物不可被夺、不可被查抄），与"只夺随身且未绑定"一致，消除"寄存与夺宝边界"的灰色理解。 |

**OQ2 · 世界时钟与赛季细节 —— 已定为一套「双时间轴 + 托管」规则**

| 维度 | 收敛结论（已定） |
|---|---|
| 赛季现实档位 | 默认**标准服 12 现实周**（创作者确认）；预留 8 周「疾风」/16 周「长歌」两档为 P1（按同一规则缩放）。一服一「界」（共享世界实例），本期只开一界。 |
| 世界时间（寿元模型创作者确认 2026-09-09，取代原 B-1 的 R 校准） | 服务器权威「纪元历」：**1 游戏年 = 现实 1 天（1 世界日 ≈ 现实 4 分钟）**，全局恒定；寿元/闭关/事件时长均按此轴计价，**登录与否都流逝**。寿元＝**入世随机基数（凡人之躯示例 70–100 岁）＋ 逐次大境界渡劫的随机增寿**（区间示例见 FR-3），不再按境界设固定寿元表；小阶晋升不加寿元。一纪元（标准档 84 现实天）＝ 84 世界年，形成"一届修士从生到老 ≈ 一个赛季"的节奏。 |
| 离线托管 | 默认「挂机闭关」：**仅入庇护后生效**（见 OQ1 护栏③④；未入庇护的即时下线先按「逃遁失败」结算再进入托管）。离线期间按资质/资源自动修炼，**收益设上限**（≈现实 24h 有效闭关，超出为枯坐无益）；庇护中的离线不承担主动风险，但会错过限时事件（秘境开启、宗门大会、大劫预兆）。离线前可预设托管意图（闭关冲刺某功法 / 打理坊市委托）。 |
| 死亡/转世/道统 | 死亡=一世结束，真灵转世；赛季内可多世（见 §4 US-4、§5 FR-7）；赛季末「天地大劫」全员应劫，未飞升者强制转世入下纪元。 |

**寿元/赛季节奏自洽约束（时间轴已由创作者定死为 1 年=1 天；执行交给 WS-157 数值校准）**

时间轴 R 不再参与校准（创作者已定 **1 游戏年 = 现实 1 天**）。仍需数值联合校准的是：**突破增寿区间表、修炼/突破的节奏曲线、一世目标境界**。可验收约束（k1 为硬性收验目标）：
- **k1（硬门槛）**：休闲玩家在寿元耗尽前，能稳定体验「练气 → 筑基 → 金丹」的完整上升段（"一世能玩到金丹"是赛季首版可玩性底线）。
- k2：新手庇护期（现实 72h）内正常游玩不会寿元自然耗尽（出生下限 70 岁 ≫ 3 天，天然满足；保留为观测项）。
- k3：免费额度"至首次筑基渡劫"（C-2）与一世前期（练气→筑基）的现实耗时匹配，避免"额度未用完寿元先尽"。
- k4：标准档 84 现实天 ≈ 多数人一世寿元量级，形成"寿元让你**可能活不到大劫**（风险）、突破增寿让你**活过大劫直面大劫**（常态）"的节奏。
- 交付物：WS-157 输出自洽的**突破增寿区间表 + 修炼节奏曲线 + 一世目标境界回填值**并附推导，回填本文 §12-M/N。

## 1. 问题陈述与目标

### 1.1 现状痛点（要解决什么）

- 修仙单机/弱联网游戏常见「后期空虚」：境界满、事件重复、世界不因我而变；玩家的选择不产生持久痕迹。
- 「修仙的残酷」多以文案/事件呈现，缺少**机制化的天道无情**：寿元、业力、天劫常常只是背景设定。
- 既有修仙网游/文字游戏普遍是「数值军备竞赛 + 版规限冲突」，缺少既能强互动又不靠运营镇压的自平衡结构。
- AI 叙事型产品（类型 A 说书人）无共享世界权威与一致性，无法支撑多人排行与因果。

### 1.2 本作主张

以规则引擎为唯一数值/因果权威，LLM 提供叙事与角色言行（类型 B，D1/D3）；共享世界 + 赛季轮回 + 因果自平衡的强 PvP，构成"每世不重样、选择留痕、天道有眼"的核心差异。

### 1.3 成功指标（KPI）与度量

| KPI | 度量方式 | 目标基准（首测后定标） |
|---|---|---|
| 免费→付费转化率 | 首次购买仙晶/月票 ÷ 激活试玩账号 | TBD（≥行业中位，首测定） |
| 次留/周留 | 激活次日 / 7 日回归率 | TBD |

## 4. 用户故事与验收标准

> 验收格式：给定(Given)…当(When)…则(Then)。每故事含正常流 + 至少一条异常流。

**US-1 一世修炼与突破**（P1/P2）
作为修士，我想按功法修炼、积累修为、突破境界，以便变强并延续寿元。
- AC1-正常：给定我练气九层且修为满，当我选择「突破筑基」并准备护脉丹/阵法，则进入渡劫流程；成功则升至筑基并按区间随机增寿（示例 +20–40，见 FR-3），失败则按档受创（见 FR-4）。
- AC2-异常：给定我修为未满或心境值过低，当我尝试强行突破，则系统拒绝或标红「根基不稳」，提示补齐条件，不消耗突破资源。
- AC3-异常：给定我寿元仅剩约 10 岁（＝现实 10 天），当我进入长闭关，则系统在闭关途中强制触发「大限将至」事件供我中断抉择，不允许我在闭关中"默默坐化"无提示（离线闭关寿元照常流逝，不豁免）。

**US-2 因果与业力**（P3/P1）
作为玩家，我想知道滥杀的代价、也能行善积德，以便在"自由"与"天道有眼"间做选择。
- AC1-正常：给定我击杀一名无仇怨同境修士，则我业力 +Δ、击杀者天机显影时长 +Δ，功德榜观感变化，符合 §FR-5 规则。
- AC2-异常：给定我业力已高，当我试图再入安全区，则坊市守卫会拒绝/加价（体验层呈现），不出现"规则引擎静默拒绝"的困惑。
- AC3-异常：给定我攻击真正入庇护的对象（新手 / 已入庇护的离线者 / 安全区内），则系统拒绝执行并提示「天道庇护」，同时攻击者被记业力重罚（防试探性攻击）；对「逃遁失败」的即时下线者不在此列（见 US-3 AC2）。

**US-3 杀人夺宝与悬赏**（P3）
作为强者，我想在冲突区击败他人并夺取未绑定财货，同时承担被标记的风险；作为弱者，我想悬赏复仇。
- AC1-正常：给定冲突区两人均为在线且无庇护，当我击败对方，则可拾取其未绑定随身灵石（有上限）与 1 件未绑定物件，杀人者业力上升并可能被「天机显影」。
- AC2-异常：给定对方已入庇护（新手/安全区/脱战后安全离线的庇护者），则「夺宝/攻击」指令不可用；给定对方在斗法中或冲突区即时下线（未入庇护），则视为「逃遁失败」——斗法中按判负结算、我可夺其未绑定随身财货，非斗法则触发一次「遗财」折损结算（均受夺宝上限/递减约束）。
- AC3-异常：给定我当日已多次夺宝，则后续掉落按 D9 收益递减至下限，界面以「因果已淡，所获寥寥」呈现（不暴露防刷数值）。

**US-4 死亡与转世**（P1–P4）
作为玩家，我希望死亡不是删号，而是带道统的新一世，以便坦然接受天道无常并继续。
- AC1-正常：给定我本世陨落，则进入「转世结算」：展示本世大事记、业力/功德结转、获得道统传承点，随后降生于当前纪元继续。
- AC2-异常：给定本纪元已进入大劫结算期（倒计时），则死亡后不再即时转世，统一进入纪元结算排队（避免钻空子重置大劫状态）。
- AC3-异常：给定我连续快速送死（如 1 小时内多次），则转世进入冷却/引导保护，防恶意刷传承点与自杀流。

**US-5 宗门与道统传承**（P1/P2/P5）
作为寿元将尽的老修士，我想把衣钵传与弟子，以便道统延续并留下传说。
- AC1-正常：给定我有一名拜入门下的弟子且双方在线，当我执行「传功/传承」，则按因果链转移部分修为/功法/法宝（受上限与忠诚/资质约束），事件记入世界大事记。
- AC2-异常：给定弟子已离线或背弃师门，则传承失败并给出原因。
- AC3-异常：给定我强行传功给资质不匹配者，则系统提示「恐爆体/走火」并允许我取消。

**US-6 赛季终局与大劫**（全部）
作为修士，我希望在大劫前有明确抉择窗口，以便体面收尾本纪元。
- AC1-正常：给定纪元进入「大劫倒数 N 天」，则全服可见倒计时、异象事件频发、飞升机缘/避劫至宝投放；结束时按 §FR-10 结算榜单与传说。
- AC2-异常：给定我在大劫降临瞬间正在闭关/渡劫，则结算以「纪元终态」为准，不因个人进行中动作而卡死（强一致性）。
- AC3-异常：给定结算后我未飞升，则自动转世入新纪元，携带道统与（按规则的）轻量出身优势，不丢失账号。

**US-7 免费试玩转付费**（P4）
作为新玩家，我希望免费额度足够体验"一世前期"，以便决定是否购买。
- AC1-正常：给定新账号激活，则获赠「初入道」额度（仙晶），足以体验开局至首次筑基渡劫；额度用尽前有非打扰式提示。
- AC2-异常：给定额度用尽且未购买，则进入「苦修模式」：规则性挂机/修炼/公共事件可继续，AI 深度交互锁定并引导购买；不踢出、不删角色。**首次渡劫失败/死亡不归零「初入道」额度**（C-2 已定），苦修模式门槛不卡在玩家第一次失败上。
- AC3-异常：给定我购买仙晶后当日到账延迟（Steam 回调未达），则系统先授「临时额度」防断档，到账后核销（需架构确认实现成本）。

**US-8 内容合规与 AI 边界**（运营/安全）
作为运营，我希望玩家文本与 AI 生成内容有护栏，以便过审与防滥用。
- AC1-正常：给定玩家输入含违禁词，则拦截/替换并记录，不进入 AI 生成管线。
- AC2-异常：给定 AI 提案"凭空给玩家一百万灵石"，则规则引擎拒绝并记审计日志（幻觉/越权防护）。
- AC3-异常：给定同一玩家高频触发 AI 交互，则按 D9 限额降级为规则性回应并提示「灵气稀薄，暂不可推演」。

## 5. 功能需求（FR）

> 每项含：描述、输入/输出、边界、错误处理。编号供架构与 PVDA 引用。数值均「假设」，标注在文内。

### FR-1 世界与赛季（纪元）生命周期
- 描述：一个共享世界 = 一个「纪元」。纪元含：开幕（开天辟地，玩家降生）→ 演进（世界时钟推进）→ 大劫倒数 → 大劫结算 → 关闭（数据归档为下纪元「上古传说」素材）。
- 输入/输出：运营建服参数（档位、预算、开服时间）→ 世界状态机事件广播给全员。
- 边界：本期单服单界；多界（合服/新服）为 P2。一纪元跨度由档位直接给定（时间轴 1 年＝1 现实天）：标准档 84 现实天＝84 世界年，8/16 周档为 56/112 世界年；"大劫不等人"由赛季现实天数天然锚定，无需反推世界年跨度。
- 错误处理：结算期禁止新角色降生；开服/关服公告先行，杜绝"关服吞号"。

### FR-2 世界时钟与时间流速
- 描述：服务器权威「纪元历」；**1 世界日 ≈ 现实 4 分钟（1 游戏年 = 现实 1 天，创作者确认 2026-09-09）**，为全局恒定时间轴，不随在线人数或个体状态波动；寿元/闭关/事件时长全部按此轴计价，**登录与否都流逝**。寿元以"岁（＝现实天）"倒计时向玩家呈现。
- 输入/输出：服务器 tick → 各修士寿元倒计时、事件排程、天象更新。
- 边界：时间轴全局恒定；「疾风/长歌」档位仅改赛季总天数（56/112 现实天），不改变 1 年＝1 天的流速。
- 错误处理：服务器时间回拨防护（单调时钟）；掉线期间的寿元流逝按服务器纪元历补算，不按客户端。

### FR-3 修炼 / 境界 / 寿元
- 描述：境界阶梯（示例刻度，待数值策划校准）：凡人 → 练气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 大乘 → 渡劫（飞升判定）。每大境界含 3 小阶。**寿元模型（创作者确认 2026-09-09）**：寿元＝**入世随机基数 ＋ 逐次大境界渡劫的随机增寿**，不再按境界设固定寿元刻度。示例区间（示意，数值待 WS-157 精调）：
  - 入世（凡人之躯）：出生随机 **70–100** 岁（转世/新角色重新随机）
  - 破入练气：+10–20｜破入筑基：+20–40｜破入金丹：+40–80｜破入元婴：+80–150｜破入化神：+150–300
  - 炼虚/大乘：增寿幅度继续放大；飞升后不再受寿元约束
  - 例：出生 80 → 练气 +15 → 筑基 +30 ≈ 125 岁可活；延寿宝/道体/功德等可再叠加
- 玩家会怎么做 → 系统如何响应：修炼(消耗时间+资源+功法) → 修为增长曲线结算；闭关(见 FR-2/托管) → 加速修炼但**寿元照常按现实时间流逝，离线闭关不豁免**；到瓶颈 → 需突破（FR-4）→ 渡劫成功 → 境界提升 + 区间随机增寿 → 寿元倒计时更新。
- 边界：同一大境界内小阶晋升主要加修为/实力，**寿元只在渡劫（大境界破境）节点增加**；寿元大限前 10 岁（10 现实天）触发强制「大限将至」提示；寿元耗尽即坐化→转世（FR-7/US-4），不是删号。
- 错误处理：寿元耗尽瞬间正在渡劫 → 以渡劫结果优先结算，避免双杀判定；离线期间寿尽 → 下次登录进入坐化转世结算，道统/出身保留。

### FR-4 突破 / 天劫（机制化天道）
- 描述：突破大境界触发天劫。劫云强度 = f(目标境界、业力、功德、准备度)。玩家在劫前可：硬扛 / 用法宝阵法丹药（消耗品）/ 请护法（多人协作）/ 延后。
- 输入/输出：突破申请（含消耗品/护法列表）→ 规则引擎计算成功率与结果 → LLM 生成渡劫叙事 → 事件入总账。
- 玩家会怎么做 → 系统如何响应：业力高者见「劫云含黑煞」提示 → 天劫威力提升；功德高者见「紫气护体」→ 成功率加成。
- 边界：渡劫成功即按 FR-3 区间**随机增寿**（寿元只加在渡劫节点，小阶晋升不加）；失败代价分档（假设：轻伤 / 道基受损 / 陨落），陨落概率受准备度与业力影响，最低不为 0（天道无情但可管理）。
- 错误处理：渡劫中掉线 → 按「已做准备的最优自动应对」结算一次，结果入账，防拔线逃劫。

### FR-5 业力 / 功德 / 心魔 / 天道标记
- 描述：每个修士一条「业—德」账。业力来源：无端杀人（同境/低境/庇护对象权重高）、破誓、夺宝过度；功德来源：除凶（击杀高业力者）、护佑、善行事件、传道。心魔 = f(业力、执念、因果未了、功法冲突)。
- 玩家会怎么做 → 系统如何响应：业力到阈值 → 触发「天机显影」（名字+大致方位广播为凶人，诛之得功德）→ 形成自平衡猎杀链；心魔触发 → 入心魔事件（LLM 叙事），失败 → 「入魔」临时状态（战力反转/失控为 NPC 行为若干世界日）或道基受损。
- 边界：天机显影有距离/时间窗；功德对天劫与奇遇有加成上限（防刷功德）。业力可经「斩业/行善」缓慢消解，不可清零购买（防 pay-to-clean）。
- 错误处理：AI 生成的心魔内容必须可安全退出（玩家可「斩念自醒」消耗资源强制结束），不得无限循环锁角色。

### FR-6 斗法 / PvP / 杀人夺宝（OQ1 载体）
- 描述：分安全区与冲突区（见 §0.3 OQ1）。斗法按战力指数+境界+环境判定（规则引擎）；击杀成立才触发夺宝与业力。
- 玩家会怎么做 → 系统如何响应：发起攻击（双方在线、均未入庇护、目标在冲突区）→ 进入斗法结算（可 LLM 描述战况）→ 胜者拾取（上限/递减）、业力入账、事件入大事记。
- 边界（A-1/A-2 修订）：绑定/道印之物不掉落；**庇护对象（新手 / 已入庇护的离线者 / 安全区内）不可攻击**，强攻遭天道降罚（业力暴涨 + 天机显影）；**斗法中/冲突区即时下线不视为入庇护**，按「逃遁失败」结算——斗法中判负可被夺其未绑定随身财货、冲突区非斗法记一次「遗财」折损（不伤性命），防"下线逃斗/下线存宝"；**坊市寄存 = 离线前安置财货的标准路径**（收保管费，寄存物不可被夺，详见 FR-8）；单日夺宝收益递减（D9）；悬赏系统：受害者可挂赏金，击杀凶人者得赏（详见 §6.4）。
- 错误处理：并发同杀同一目标 → 按「最后一击+伤害贡献」规则分配，防双拿；击杀瞬间目标转世 → 结算到转世前状态；击杀瞬间目标下线 → 按逃遁失败处理，不豁免结算。

### FR-7 死亡 / 转世 / 夺舍 / 道统继承（OQ2 载体）
- 描述：死亡方式：寿终坐化 / 斗法被杀 / 渡劫陨落 / 心魔道消。死亡 → 转世结算（大事记、业德结转、道统传承点）。**寿尽坐化是常规一世结局（创作者寿元模型：寿元按现实时间流逝、离线照扣；寿尽非删号）**。夺舍为稀有事件：借特定至宝/秘境对他人躯壳夺舍，高业力、可失败（真灵反噬=陨落）。道统继承：师徒/血脉/宗门传功。
- 玩家会怎么做 → 系统如何响应：本世结束 → 结算界面 → 降生选择（道统点消费项：出身/灵根品质/初始功法，设上限保持公平）→ 入世（出生寿元重新随机 70–100）。
- 边界：道统传承点为轻量元进度，赛季间保留、有赛季上限（防滚雪球）；夺舍仅对满足条件的「无主/重伤」目标或事件开放，不做常规玩法。离线闭关不豁免寿元，但仍受三护栏庇护（不会被杀/被夺）。
- 错误处理：见 US-4 AC2/AC3（结算期统一排队、自杀冷却）；离线寿尽 → 登录时结算坐化转世，不吞号。

### FR-8 资源经济（零和与灵石/仙晶双币）
- 描述：见 §0.3 与 §8 字段。**双币结构（C-1 已定）**。*命名对齐：父任务 D4/D6 所述"内购灵石"，在本版**细化**为两个币种——非推翻决策，而是拆分"可被夺的世内货币"与"驱动 AI 的付费货币"，防止杀人夺宝夺走玩家真钱购买的内容：*
  - **灵石**：世内经济货币。来源：历练、任务、坊市、宗门俸禄、夺宝。用途：世内交易（法宝/丹药/情报/悬赏/捐献）。**可交易、可被夺、零和**。
  - **仙晶**：付费货币（D4/D6"内购"项的正式命名）。来源：买断附赠、内购、月票、免费额度。用途：驱动**个人 AI 内容**（天机推演、秘境入场、NPC 深度论道、著书立说等）。**绑定、不可交易、不可掉落**（防"杀号掉真钱"）。
  - 后端：仙晶消耗 → 折算私有 AI token；公共事件走公共池（见 FR-9/D9）。
- 玩家会怎么做 → 系统如何响应：坊市挂单/直购 → 撮合；被夺只影响灵石；AI 深度交互扣仙晶。
- 边界（A-2）：世界灵石总投放受纪元灵气总量约束（灵气稀释机制，见 FR-9）；仙晶购买力与战力解耦（防 pay-to-win 口碑）。**坊市寄存**：玩家可将随身财货寄存坊市/宗门库（收保管费，寄存物不可被夺、不可被查抄），是"离线/闭关前安置财货"与对抗"下线存宝"的标准路径，与"只夺随身且未绑定"的夺宝边界一致。庇护中（§0.3 护栏③）的随身财货不可交易/转移，防"庇护=移动保险库"。
- 错误处理：交易欺诈（先钱后货跑路）由「天道契约/担保」机制约束（系统担保或凭据，P0 做系统担保撮合）。

### FR-9 公共世界事件 / 秘境 / 事件总账 / 灵气稀释
- 描述：公共事件（秘境开启、宗门大会、异宝出世、天灾）由服务器限量排程、统一生成、全员广播（一次生成多人消费，D9）。规则引擎产出数值，LLM 生成叙事；所有公共状态变更写「世界事件总账」（who/when/what/world-after），全员同源可见。
- 灵气稀释（天道无情的零和资源载体）：纪元灵气总量固定，境界越高者维持/修炼占用越多 → 高阶修士越多，全服修炼速率越慢 → 自然压迫冲突与"上位淘汰"。灵气总量变化随大事记广播（如「天地灵气稀薄了」）。
- 玩家会怎么做 → 系统如何响应：参与秘境需入场券（灵石/仙晶/宗门贡献）→ 秘境实例事件 → 产出资源+奇遇 → 入总账。
- 边界：公共事件频率/预算上限（D9）；秘境实例并发上限；公开事件必须有「世界-after」一致性快照。
- 错误处理：同一公共宝物被多人同时竞夺 → 按事件规则（争夺战/名额/时序）裁决，不得复制产出。

### FR-10 排行榜与赛季结算（D7）
- 描述：六榜 + 口径：
  1. 境界榜：按「最终境界 → 小阶 → 达成时间序」排（力量榜）。
  2. 战力榜：规则引擎战力指数（境界/功法/法宝/秘术合成），口径公开、明细隐藏部分（防精确反推配装，仅给区间）。
  3. 资产榜：灵石 + 可估值资产现值（净资产）。上榜即树大招风（高资产者在冲突区被夺收益有加成？——不加成，保持零和公平，仅靠暴露制造张力，假设）。
  4. 凶名榜：按业力（恶意向）排。上榜者新纪元仍「恶名在外」（软性）。
  5. 传奇榜：按「传奇事迹」声望（见 FR-12 事迹判定），软性。
  6. 道行榜：累计有效修行深度（境界×时间加权），软性。
  - 宗门/势力榜：P1。
- 结算规则：纪元末冻结快照 → 按榜发奖 → 奖励在**新纪元发放**。**铁律：凶名/传奇/道行等非力量榜只发软性奖励**（称号、道号、传说写入新纪元典籍/遗迹/雕塑、"世界记住你"），绝不发硬数值。境界/战力等力量榜可发轻量出身/资源奖励，但设上限防马太效应（假设）。
- 玩家会怎么做 → 系统如何响应：冲榜行为（如囤资产）→ 上榜 → 暴露风险与荣耀并存；结算 → 奖励 + 事迹入下纪元内容库。
- 错误处理：结算期封榜；同分并列处理；刷榜行为（转世卡名次等）→ 以「当世最高成就」为准计名次并审计。

### FR-11 计费 / 免费额度 / 月票（D4/D6）
- 描述：买断本体 + 仙晶内购（D6"内购灵石"细化为仙晶，C-1）+ 月票 DLC。免费试玩（C-2 已定）：新账号**激活即得一次性「初入道」仙晶**，口径＝足以完成「练气 → 首次筑基渡劫」的**完整体验**；**首次渡劫失败或死亡不归零额度**，苦修模式门槛不卡在玩家第一次失败上。额度量级由架构成本模型（WS-157）回填，本版不拍数字。额度用尽 → 苦修模式（规则性玩法可继续，AI 深度锁定）→ 付费解锁。该里程碑与一世前期（练气→筑基）现实耗时匹配（§0.3 k3）。
- 月票（DLC）范围：期内每日仙晶津贴、高消耗内容折扣、专属奇遇频率提升、月票称号/道号；**不含独占战力数值**（公平性，假设）。
- 玩家界面形态：**全程灵石/仙晶计价，绝不显示 token/字/条数/成本**；消耗以世内理由呈现（推演需燃香、秘境入场费、天机阁阁规），充值/订阅走 Steam 原生流程。
- 输入/输出：消费请求 → 仙晶余额核销 → 后端折算私有 token → 若超 D9 单账号上限 → 降级规则性响应。
- 错误处理：见 US-7 AC3（Steam 回调延迟临时额度）；重复扣款防护；未成年人/地区合规见 §9。

### FR-12 AI 生成边界与护栏（D3/D9 + 关键约束 1/2）
- 描述：AI 负责生成：事件叙事、NPC 言行、宗门动态、秘境/奇遇文本、天劫/心魔叙事、结算后记、下纪元传说库素材。**AI 绝不直接改任何公共数值/因果**——只能向规则引擎提交「结构化事件提案」（who/what/欲改变量/概率建议），由规则引擎校验、执行、落总账。
- 玩家自由输入边界：行为指令自由文本 → 意图解析 → 规则引擎判定合法性 → AI 写结果（例："我要在坊市摆摊卖符"合法；"我要凭空得一百万灵石"被拒并转为"痴心妄想"叙事反馈）。玩家聊天（传音/宗门/私聊）自由但过内容过滤与分级。
- 护栏：内容过滤（政治/色情/未成年/人身/赌博）；实体一致性绑定（人名/地名/势力跨事件一致）；幻觉/越权校验（任何状态变更以规则引擎结果为准）；公共事件预算与频率上限（D9）；AI 输出可审计（留档）。
- 输入/输出：玩家请求/事件触发 → LLM 调用（私有或公共池）→ 文本 + 提案 → 引擎执行。
- 错误处理：LLM 超时/失败 → 降级规则性叙事（预设模板）不阻塞玩法；敏感内容命中 → 拦截并记录，不回显原句。

### FR-13 宗门 / 结盟 / 师徒 / 悬赏（多人关系，P0 轻量版）
- 描述：P0 提供轻量组织：结拜/师徒/宗门（宗门：创建、入宗、驻地、贡献、宗门大会事件）。关系以「因果链」落库，供 AI 生成相关事件（寻仇、护短、清理门户）。
- 玩家会怎么做 → 系统如何响应：结盟 → 因果链建立 → 同门被欺可请宗门出头（NPC 或玩家援手）。悬赏：挂赏 → 全服可见 → 击杀凶人者领赏（规则结算，防骗赏；详见 §6.4）。
- 边界：本期宗门功能为轻量（驻地/贡献/事件），大型攻城/势力战为 P1（与宗门/势力榜一并）。
- 错误处理：退宗/叛宗 → 因果链处理（功法回收或追杀事件，规则化）。

### FR-14 信息与可感知性（UX/世界记住你）
- 描述：天道无情必须**可感知**：寿元以「大限卦象」直观呈现；业力以「头顶煞气/观气术」呈现；天机显影有全服事件广播；事迹写入「天地鉴/大事记」供查阅。玩家可「著书立说」（消耗仙晶）把本世经历写成典籍，被 AI 校验后入下纪元素材库。
- 输入/输出：玩家查询（观气/推演）→ 返回带滤镜信息（允许模糊，如"此人业力深重"而非精确数值）。
- 边界：精确数值只对自己可见；对他人为卦象/观感分级，保留神秘感与反侦察。
- 错误处理：信息类目权限与欺诈（伪装信息）由规则引擎校验。

## 6. 玩家目标与任务系统

> 创作者点名专章。本作**无固定主线、无任务清单**：系统不派发"任务"，而是供给**目标源**；玩家自定优先级，可接可拒、有后果。以下每条给出「玩家会怎么做 → 系统如何响应」，供架构据此建模（对应库表见 §8 新增 Goal / EventChain / Bounty；新增假设见 §12-K/L）。

### 6.1 目标源总览

| 目标源 | 驱动节奏 | 拒绝/放弃后果 | 关联 |
|---|---|---|---|
| 一世道途目标 | 寿元倒计时长线驱动 | 寿元耗尽坐化 | FR-3/4、US-1 |
| 机缘与事件 | 服务器限量排程 + AI 生成 | 放弃无惩罚，机缘转投他人 | FR-9/12 |
| 悬赏与复仇 | 玩家因果触发 | 不接无惩罚；被害者可挂赏 | FR-6/13、US-3 |
| 宗门与师门 | 宗门运营周期 | 退宗承受因果链处理 | FR-13、US-5 |
| 赛季大目标 | 纪元大劫倒计时 | 未飞升→强制转世 | FR-1/7/10、US-6 |
| 新手引导线 | 72h 庇护期一次性 | 引导外无强制，不完成不惩罚 | FR-11、US-7 |

### 6.2 一世道途目标（境界推进 / 延寿 / 飞升）
- **玩家会怎么做**：开局选功法路线（剑修/丹修/体修…）→ 规划修炼与历练的时间分配 → 面对寿元倒计时做决策（稳扎突破 vs 冒险闭关 vs 求延寿宝）→ 高阶后谋划飞升条件（境界/功德/机缘）。
- **系统如何响应**：境界阶梯 + 修为曲线 + 寿元倒计时（FR-3，寿元按现实时间 1:1 流逝）→ 突破触发天劫（FR-4，劫威与业力/功德挂钩）→ 大限前 10 岁（10 现实天）强制预警（US-1 AC3）→ 飞升作为纪元终局大目标的个人分支（与 §6.6 联动）。以「道途卦象 / 修炼进度」形态呈现，**不列任务清单**。
- **建模块**：修士 Character（修为/寿元/心境）+ Goal（道途进度）。

### 6.3 机缘与事件（AI 生成事件链 / 秘境 / 天机推演）
- **玩家会怎么做**：收到事件邀约（宗门来信 / 秘境开启 / 异象示警 / 奇遇线索）→ 评估风险收益后选择**接 / 拒 / 观望** → 进入后自由输入行为指令 → 可消耗仙晶做「天机推演」获取额外线索 → 一个选择可能引出后续关联事件（事件链）。
- **系统如何响应**：服务器限量排程公共事件（FR-9）→ AI 生成叙事与选项（FR-12，只提案不改数值）→ 规则引擎对选择落因果与数值（写入世界事件总账 who/when/what/world-after）→ 拒绝则机缘转投他人或消散，**无惩罚**；事件后果可正可负（增益 / 业力 / 仇怨 / 身死）。
- **建模块**：EventChain（链头事件 + 关联引用 + 分支），跨事件可追溯；秘境为事件的实例化载体之一。

### 6.4 悬赏与复仇（FR-6 / FR-13）
- **玩家会怎么做**：被害后挂赏悬凶（消耗灵石，可选留名/匿名）→ 猎手在告示榜接令 → 按目标行迹追猎 → 击杀/击败凶人后凭战果领赏。
- **系统如何响应**：悬赏令全服可见（告示榜）→ 领赏由规则引擎按战果结算（**防骗赏/防双领**）→ 因果链记录仇怨（KarmaLink）→ 支撑 AI 后续生成复仇事件。匿名悬赏须经「真实被害因果」校验，防恶意诬陷。
- **建模块**：Bounty（挂赏者 / 目标 / 赏金 / 状态 / 校验）。

### 6.5 宗门与师门（俸禄 / 传功 / 道统）
- **玩家会怎么做**：入宗领俸禄与贡献事务（非强制、无清单）→ 拜师/收徒 → 对弟子传功、临终前安排道统继承 → 或自创宗门收人。
- **系统如何响应**：宗门俸禄/贡献结算（FR-13）→ 师徒因果链管理（US-5）→ 传功受资质/忠诚约束，强行传功有「恐爆体/走火」提示 → 寿元尽前完成传承可结「道统传承点」（FR-7），事迹写入传说。
- **建模块**：KarmaLink（师徒/宗门）+ Legacy（道统点）+ Goal（宗门贡献，可选）。

### 6.6 赛季大目标（应对天地大劫 / 飞升或转世收尾）
- **玩家会怎么做**：纪元进入大劫倒计时后，在窗口内抉择：抢飞升机缘 / 囤避劫至宝 / 安排传承道统 / 接受转世 → 提前规划本世收尾。
- **系统如何响应**：全服大劫倒计时 + 异象事件频发（FR-1/FR-9、US-6）→ 纪元结算封榜发奖（FR-10）→ 未飞升者统一转世（FR-7），道统与轻量出身优势结转新纪元。
- **建模块**：Season 状态机 + RankSnapshot + Legacy。

### 6.7 新手引导线（免费额度「初入道」内目标）
- **玩家会怎么做**：新账号在 72h 庇护期内完成「练气 → 首次筑基渡劫」——这是免费额度能覆盖的一世前期完整体验。
- **系统如何响应**：新手庇护（§0.3 护栏①，72h 且境界≤筑基初）→ 免费额度「初入道」（FR-11/C-2，激活即得、首次失败/死亡不归零）→ 引导以目标进度形态呈现（"道途初启"），**非任务清单** → 额度与一世前期现实耗时匹配（§0.3 k3）→ 用尽后进入苦修模式（AI 深度交互锁定并引导购买；不踢出、不删角色）。
- **建模块**：PlayerAccount（免费额度状态）+ Goal（引导线）。

### 6.8 明确"不做"（目标形态边界）
- **无日常打卡式任务**：不做"每日登录领奖 / 每日任务清单"驱动；上线没有必做事项。
- **无强制主线**：没有必须推进的剧情线；任何"目标"都可拒绝、可放弃，拒绝不惩罚。
- **不把引导做成任务系统**：新手引导以目标进度与机缘形态呈现，不显示"任务列表 / 支线编号"。
- **意外后果兜底**：放弃目标若导致重要信息不可达（如错过宗门大会），以事件回放/天机推演（仙晶）可补，不设"永久错过"的负反馈。

## 7. 业务流程与状态流转

### 7.1 修士「一世」状态机

```
入世(降生/庇护期) ──► 成长(修炼/历练/坊市/结盟/争斗) ──► 渡劫(大境界突破) ─┐
      ▲                        │  ▲            │   ▲                        │成功
      │                        ▼  │(受创)       ▼   │(心魔)                  ▼
      │                    重伤/道基损      入魔(临时) ─►(自醒/除魔)    境界提升(寿元+)
      │                        │                          │                 │
      └──(转世)◄── 陨落 ◄──────┴──────────────────────────┘                 │
                                              │                              │
                                大限/被杀/渡劫陨落/道消    飞升(纪元末判定)──┘
```
- 关键状态：`庇护期`、`静修/庇护`（仅经"脱战+离开冲突区后离线"或主动「闭关归隐」进入，见 §0.3 护栏③）、`逃遁失败`（斗法中/冲突区即时下线被引擎结算，随身未绑定财货可被夺，见 FR-6）、`闭关`(托管，不可行动可被唤醒)、`重伤`、`入魔`、`大限预警`、`应劫待结算`。
- 目标状态（§6）作为修士状态的附属记录，随状态机流转（如庇护期内的引导线目标、寿元大限期的道统安排目标）。
- 状态变更唯一入口：规则引擎（防客户端作弊）；AI 只提交提案。

### 7.2 纪元（赛季）状态机

```
开幕(开天辟地, 放号) ──► 演进(世界时钟/公共事件/托管) ──► 大劫倒数N天
     ▲                                                          │
     │                                                          ▼
  新纪元开幕 ◄── 数据归档(传说库/素材) ◄── 大劫结算(封榜/转世/发奖/写传说)
```

## 9. 非功能需求

### 9.1 性能与并发
- 世界时钟 tick 精度：结算误差 < 1 世界日（假设目标）；公共事件广播延迟 < 5s（假设）；斗法/突破结算 < 2s（假设）。
- 单服在线目标：首测定标（如 1,000–5,000 CCU 档），架构按此设计；高峰期大劫结算需可水平扩展。
- LLM 延迟容忍：私有叙事可异步（先给规则结果再补文）；公共广播可排队，不阻塞核心结算。

### 9.2 成本护栏（D9，关键约束 1）
- 每账号/每赛季 AI 用量上限 + 收益递减；公共事件统一生成、限量、广播（一次生成多人消费）。
- 成本两池：私有池（仙晶/免费额度）与公共池（运营预算），报表按池统计；定价必须覆盖：模型成本 + Steam 抽成（≈30%）+ 服务器运营（父任务硬要求），数字由架构出模型，本方案不编。

### 9.3 安全合规
- AI 内容护栏（FR-12）+ 可审计留档；玩家 UGC 过滤；分级（Steam 内容问卷/年龄分级，OQ4 归发行）。
- 无涉赌（开箱类规避）：付费即得明确内容，不做随机抽奖式付费（假设方向，需发行确认）。
- 未成年人/地区合规、隐私（Steam ID 关联最小化）——OQ4 一并决策。

### 9.4 兼容与集成
- 客户端技术选型 = OQ5（架构/客户端负责人）；本方案只要求：PC/Steam 买断、原生内购、支持中文本地化先行。
- 集成依赖：Steamworks（认证/内购/订阅/DLC）、LLM 网关（OQ3）、规则引擎、事件总账、监控告警。

### 9.5 可观测性
- 记录：仙晶→token 折算对账、公共事件单条成本、榜单异常、业力/击杀分布、庇护期被杀数（=0 硬门槛）、**仙晶→token 折算对账误差率（P0 硬观测项，与"庇护期被杀=0"同级，防计费链路静默漏损；阈值由 WS-157 成本模型给出）**。
